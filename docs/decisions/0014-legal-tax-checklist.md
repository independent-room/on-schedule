# ADR-0014: 법무·등록·세무 + 베타 인프라 비용

상태: 채택
일자: 2026-05-03 (갱신: 2026-05-05 — 베타 인프라 비용 갱신, 도메인 결정 반영)

## 컨텍스트

사업 운영을 위한 법적 신고·등록·세무 의무를 한 곳에 정리한다. 1인 + 검증 단계 + 매출 0 상태에서 **진짜 0에 가까운 운영 비용**을 목표로 한다.

이미 보유 자산:
- Apple Developer Program ($99/년 — 갱신만)
- Google Play 개발자 계정 ($25 1회 — 보유)

제약:
- 1인 운영 — 시간·자본 모두 최소화
- 검증 0% → 매출 발생 전엔 모든 비용을 미루기
- 무료 자원·BP·정부 지원 적극 활용
- 법 위반 영역은 회피 (벌금·과태료가 더 비쌈)

| # | 항목 | 비용 | 소요 | 비고 |
|---|---|---|---|---|
| 1 | **사업자등록** (홈택스 온라인) | 0원 | 즉시 | 자택 주소 가능. 간이과세자로 시작 권장 |

## 베타 인프라 채택 (ADR-0003 결정 반영)

ADR-0003에서 "Railway 통합" 선택 — 플랫폼 분리 불편함 회피 + 한 콘솔 통합 우선.

| 영역 | 채택 옵션 | 베타 비용/월 |
|---|---|---|
| **API + DB + Redis + Volume (이미지)** | **Railway Hobby (NestJS + Postgres + Redis + Volume)** | **~$15-25 (~20,000-35,000원)** |
| **웹 호스팅** | Vercel Hobby | 무료 |
| **모바일 빌드** | EAS Build Free (월 30회) | 무료 |
| **푸시 알림** | Expo Push Notifications | 무제한 무료 |
| **모니터링** | Sentry Free (월 5천 에러) | 무료 |
| **알림톡** | 솔라피 (베타 5곳, 건당 ~9원, 예약당 3건) | ~6,750원 |
| **도메인** | Vercel Domains (사용자 공개 시점에 결제) | 베타엔 0원 (`vercel.app`) |

2단계: 확장 베타 (20~50곳, 3~6개월)
  iOS: TestFlight Public Link

## 근거

- 검증 단계에 풀 인프라·법무 비용을 미리 내는 것은 **검증되지 않은 가설에 대한 사전 투자**
- 무료 티어와 무료 법률 자원이 베이커리 5곳 베타 규모에 충분
- 매출 발생 후 비용 추가가 정석 — "필요할 때 추가"
- 한국 SaaS의 진짜 의무는 사업자등록·통신판매업·약관·처리방침 4개뿐, 나머지는 모두 매출 따라 단계적

## 결과

### 즉시 액션 (출시 전)
- [ ] 홈택스 사업자등록 (간이과세자로 시작)
- [ ] 정부24 통신판매업 신고
- [ ] **Railway 프로젝트 생성 + Postgres·Redis add-on**
- [ ] **Vercel Hobby 프로젝트 생성** (`xxx.vercel.app` 사용, 도메인은 사용자 공개 시점에 결제)
- [ ] BP 참고하여 약관·처리방침 자가 작성
- [ ] 처리방침에 CPO(대표) 명시
- [ ] 웹·앱 푸터에 신고번호·약관·처리방침 링크
- [ ] iOS TestFlight + Android Internal Testing 배포 환경 구성

### 사용자 공개 시점 액션
- [ ] **Vercel Domains에서 정식 도메인 결제** (.com 또는 .app)
- [ ] DNS 레코드 추가 (Vercel: 메인 / Railway: api 서브도메인)
- [ ] SSL 자동 발급 확인 (Let's Encrypt, 1-5분)

### 본격 출시 시 추가
- [ ] 포트원 가입 (0원)
- [ ] 토스페이먼츠 가맹 (포트원 통해 가입비 면제, 영세 가맹 협상)
- [ ] 토스 자동결제(빌링) 별도 계약
- [ ] 무료 법률 자원으로 약관 검토 (자동결제·중개업 위탁 처리 조항)

### 재검토 트리거
- 매출 5천만원 도달 → 일반과세 전환 + 세무 SaaS 도입 검토
- 매장 100곳+ → 변호사 자문 정식 1회 검토
- 매출 100억 도달 → ISMS 의무화 검토 (먼 미래)
