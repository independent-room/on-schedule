# ADR-0010: 메뉴 전액 선결제 모델 — 시나리오 B 단일 채택

상태: 잠정 (PMF 후 도입 시점에 발동)
일자: 2026-05-03

## 컨텍스트

ADR-0009는 "예약금/보증금"만 다룬다. 그러나 일부 베이커리/디저트(예: 주문제작 케이크 5~30만원)는 메뉴 전액을 사전에 결제 받는 모델이 적합할 수 있다. 이 본격 결제 모델을 도입하는 시점이 오면 어떤 구조로 갈지 미리 결정해 둔다.

핵심 인식: **메뉴 전액 결제는 "결제"가 본체**다. 매장 매출 본체가 우리 시스템을 거치므로 PG·정산·통신판매중개업·차지백·세금계산서가 모두 명백하게 적용된다.

제약:
- 1인 운영 — 정산·분쟁 자동화 필수
- 사장님 가입 마찰 최소 (GTM 핵심)
- 시장 표준 모델 따라가기 (야놀자/여기어때/캐치테이블 모두 시나리오 B)
- 영세 0.4% 가치는 메뉴 전액 결제에서 의미 있음 (50만원 기준 ~1만원 절감)

## 검토한 옵션

| 옵션 | 사장님 마찰 | 영세 0.4% | 1인 부담 | 시장 표준 |
|---|---|---|---|---|
| A. 매장 직접 가맹 (토스페이먼츠) | 🔴 큼 | ✅ | 🟢 가벼움 | ❌ 비표준 |
| **B. 시나리오 B 단일 — 우리 PG + 포트원 정산 분배** | 🟢 거의 없음 | ❌ (~2~2.5%) | 🟠 큼 (포트원으로 외주화 가능) | ✅ 표준 |
| C. 하이브리드 (디폴트 B + 옵션 A) | 🟢 디폴트 0 | △ 옵션 시 | 🔴 두 흐름 구현 부담 | △ |

## 결정

**옵션 B 단일 채택.** 모든 매장이 우리(온스케줄) 가맹으로 통합 처리한다. 매장 직접 가맹(시나리오 A)은 옵션으로 두지 않는다.

### 인프라
| 항목 | 선택 |
|---|---|
| PG 백엔드 | 토스페이먼츠 |
| 결제 통합 + 멀티 PG 라우팅 | 포트원(아임포트) |
| 파트너 정산 자동화 | 포트원 Partner Payments |
| 정산 주기 | 일/주/월 매장 선택 (여기어때 모델 차용) |
| 차지백 1차 대응 | 우리(온스케줄) → 매장 청구 |
| 통신판매중개업 신고 | 정부24 (1주, 면허세 ~5만원/년) |
| 변호사 자문 | 1회 필수 (10~30만원) |

## 근거

- **시장 표준 검증됨**: 야놀자, 여기어때, 캐치테이블, 무신사 등 국내 모든 주요 마켓플레이스가 시나리오 B
- **사장님 가입 마찰 최소화 = GTM 핵심**: 1인 베이커리 사장님은 PG 가맹 절차(사업자등록·통신판매업·심사 1~2주)를 부담스러워할 가능성 매우 높음. 시나리오 A를 옵션으로 두면 항상 "더 싼 옵션"으로 갈 압박이 생겨 디폴트 B의 일관된 UX가 깨짐
- **포트원으로 1인 부담 외주화 가능**: 거래 매핑·수수료 계산·정산 내역서·송금 트리거 자동화. 우리는 정책 결정·승인·분쟁 1차 대응만 담당
- **영세 0.4%는 포기, 가치 제안 재구성**: "낮은 수수료"가 아니라 "가입 마찰 0 + 빠른 정산 + 자동화"로 차별점 이동
- **단일 모델 = 코드 단순 + 운영 단순** — 1인 운영의 가장 큰 자산

## 결과

### 도입 시 구현 항목
- 포트원 SDK 통합 (NestJS API)
- 결제 위젯 임베드 (Next.js 고객 예약 페이지)
- 결제 웹훅 + 서명 검증 + 멱등성 처리
- 환불 흐름 (사장님 앱 1탭 → 자동 환불)
- 정산 콘솔 연동 (포트원 관리자 콘솔 활용)
- 차지백 1차 대응 SOP
- 통신판매중개업 신고 + 약관·푸터 표시
- 변호사 자문 (이용약관·개인정보처리방침·위탁 처리 조항)

### 가치 제안 재구성

기존(폐기): "월 매출 500만원 기준 18.7만원 절감"
신규: "예약금부터 본 결제까지, 사장님은 가입 절차 없이 시작.
정산은 다음날 입금, 환불은 자동, 노쇼는 시스템이 잡아드려요."

### 도입 트리거
- 베타에서 "본 결제도 받고 싶다" 요구 빈번 (5곳 중 3곳 이상)
- 또는 ADR-0009 3차 단계 도입 시점 — 예약금 메커니즘과 통합

### 재검토 트리거
- 매장 100곳 이상 + 매장 일부가 영세 0.4% 강력 요구 → 별도 ADR로 옵션 A 추가 검토
- 포트원/토스페이먼츠 정책·수수료 큰 변경 시
- 해외 결제(외국인 고객) 필요 시 → Stripe 등 추가
