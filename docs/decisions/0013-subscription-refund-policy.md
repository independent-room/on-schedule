# ADR-0013: 구독 환불·결제 실패 정책 — 베타 수동 → 본격 자동 (Smart Retry + 일할 환불 + 30일 보관)

상태: 잠정 (본격 출시 시 약관 확정 후 발동)
일자: 2026-05-03

## 컨텍스트

ADR-0012에서 사장님 구독료를 우리(온스케줄)가 PG 가맹점으로 받기로 결정. 따라서 환불·결제 실패·차지백·해지 처리도 100% 우리 책임.

법적 사실:
- 전자상거래법 §17: **결제 후 7일 + 미사용 = 전액 환불 의무**
- 계속거래(구독) 중도 해지권 보장 (OTT 표준약관 기준)
- 가분적 디지털콘텐츠는 미제공 부분 환불 의무
- 약관규제법 §6: 소비자에게 부당 불리한 조항 무효

업계 표준:
- 다우오피스: 잔여 50% 환불
- 우버원: 잔여 일할 환불
- YouTube Premium: 7일 미이용 환불, 그 후 No 환불
- B2B SaaS 표준: "7일 + 미사용 = 전액 환불" + "잔여 일할 환불 또는 No 환불"

## 검토한 옵션

| 환불 정책 | 사장님 친화도 | 우리 매출 영향 | 법적 리스크 |
|---|---|---|---|
| No 환불 (사용한 것으로 간주) | 🔴 낮음 | 🟢 | 🟠 약관 무효 가능성 |
| 잔여기간 50% 환불 | 🟡 중간 | 🟡 | 🟢 안전 (다우오피스 모델) |
| **잔여기간 일할 환불** | 🟢 높음 | 🟠 | 🟢 안전 (우버원 모델) |
| 전체 환불 | 🟢 | 🔴 | - |

결제 실패 처리 옵션:
- 즉시 정지 → 어뷰징 위험·CS 폭증
- **Smart Retry + Grace Period** → 표준, 회복률 50%+

## 결정

### 환불 정책

| 케이스 | 정책 |
|---|---|
| 결제 후 **7일 + 미사용** | **전액 환불** (법적 의무) |
| 사용 시작 후 중도 해지 | **잔여기간 일할 환불** (우버원 모델) |
| 처리 방식 (베타) | 1대1 수동 (이메일·알림톡 → 사장님 계좌이체 환불) |
| 처리 방식 (본격) | 사장님 앱 [구독 해지] → 자동 일할 계산 → 토스 환불 API |

### 결제 실패 처리 (본격 출시)

| 단계 | 정책 |
|---|---|
| 1차 시도 | 결제일 0시 자동 청구 |
| Soft Decline (한도/일시 오류) | **Smart Retry**: 1일 / 3일 / 7일 후 재시도 |
| Hard Decline (분실/도난/만료) | 즉시 알림 + 카드 변경 페이지 링크, 재시도 X |
| Grace Period | **3일간 서비스 유지** (즉시 차단 X) |
| 7일 후에도 미해결 | **구독 일시정지** (데이터 30일 보관) |
| 30일 후에도 미해결 | 데이터 백업 → 영구 삭제 (사전 알림 3회) |
| 카드 만료 임박 | D-30, D-7 사전 알림 + Account Updater 활용 |

### 플랜 변경
- **업그레이드**: 즉시 차액 자동 청구
- **다운그레이드**: 다음 청구일부터 적용

### 차지백 대응
- 즉시 구독 일시정지
- descriptor 명확화로 사전 예방 (브랜드명 "ONSCHEDULE", URL, 전화번호 포함)
- 결제 즉시 영수증 알림톡·이메일 자동 발송
- 카드사와 직접 분쟁 대응 SOP

### 어뷰징 방지
- 환불 후 동일 카드/사업자번호 재가입 차단 또는 환불 횟수 제한
- 무료 트라이얼 → 결제 전환 자동화 시 D-3 알림 (cancel-friendly UX)

## 약관 필수 조항

1. 환불 정책 (위 표 명시)
2. 청약철회권 (7일 + 미사용)
3. 결제 실패 처리 (grace, retry, 정지 흐름)
4. 데이터 보관 기간 (30일 등)
5. 차지백 대응 (책임 분담)
6. 어뷰징 방지 (반복 환불 제한)
7. 분쟁 해결 절차 (관할법원 등)

## 근거

- **잔여 일할 환불 채택**: 사장님 친화도 ↑ → 해지 마찰 ↓ → "환불 두려움 없는 가입" UX → 가입률 ↑
- **Smart Retry**: Chargebee/Stripe 데이터 — 결제 실패의 50%까지 회복
- **30일 데이터 보관**: 재가입 가능성 + 법적 안전 마진
- **Apple/Google 외부 결제(ADR-0012)** → 환불·해지 흐름 모두 우리가 통제 → 정책 자율도 큼

## 결과

### 베타 단계 (수동)
- 환불 = 1대1 처리
- "월 5만원 입금 부탁드려요" 알림톡
- 문제 발생 시 직접 협상

### 본격 출시 시 구현 항목
- 토스 환불 API + 일할 계산 로직 (1주 내)
- BullMQ 기반 Smart Retry cron (1일/3일/7일)
- 구독 상태 머신: `active` → `past_due` → `paused` → `canceled`
- 카드 만료 사전 알림 (D-30, D-7)
- Account Updater 통합 (토스 일부 지원)
- 영수증·이메일·알림톡 자동 발송
- 차지백 대응 SOP 문서

### 자동화 부담 (1인 관점)
- 환불 트리거: 1주 (토스 API)
- 일할 계산: 2~3일
- Smart Retry: 2~3일
- Grace Period 머신: 2~3일
- 차지백 SOP: 매뉴얼 (월 1~2건 예상)

→ **본격 출시 자동화 = 2~3주 + 약관 작성 1주**

### 약관 작성
- 베타: 자가 작성 + BP 참고 (Notion·다우오피스·캐치테이블 약관 구조 참고)
- 본격: 무료 법률상담(대한법률구조공단·K-스타트업) 또는 변호사 단건 자문 (5~10만원, 헬프미·로톡)

### 재검토 트리거
- 차지백 비율 N% 초과 → descriptor·UX 점검
- 환불률 N% 초과 → 가치 제안 또는 가격 정책 재검토
- 매장 100곳+ → 환불 정책 차등화(연간 플랜 등) 검토
