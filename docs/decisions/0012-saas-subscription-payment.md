# ADR-0012: 사장님 구독료 결제 — Multiplatform Service 패턴 (포트원 + 웹 결제, IAP 비채택)

상태: 잠정 (베타 = 수동, 본격 출시 시 자동화 발동)
일자: 2026-05-03

## 컨텍스트

사장님이 온스케줄에 매월 지불하는 구독료(예: 3~5만원)를 어떻게 받을지 결정해야 한다. 모바일 앱이 1차 채널(ADR-0002)이므로 IAP 사용 가능성이 떠올랐으나, 한국 B2B SaaS에서는 거의 사용되지 않는다.

핵심 사실:
- IAP는 정책상 가능하나 수수료 30%(또는 첫해 15%)
- 한국 사장님은 토스페이/카카오페이/계좌이체 익숙
- 정산은 D+30~60 (IAP) vs D+2 (PG)
- 환불·세금계산서 통제력 X (IAP) vs O (PG)
- Apple Guideline 3.1.3(b) "Multiplatform Service"는 외부 결제 합법 허용 (단, 앱 안에서 적극 유도 금지)

비교 사례: 캐치테이블·콜라보살롱·카페24·아임웹·Notion 한국·Slack 한국 모두 외부 결제 (IAP 사용 사례 사실상 0).

## 검토한 옵션

| 옵션 | 수수료 | 정산 | 한국 사장님 UX | 우리 통제 |
|---|---|---|---|---|
| 1. IAP (앱 내 결제) | 30% / 첫해 15% | D+30~60 | 🔴 어색 | 🔴 Apple/Google |
| **2. Reader App / Multiplatform Service 패턴 (웹 결제)** | 토스 정기결제 ~3.4% / 영세 0.4% | D+2 | 🟢 익숙 | 🟢 우리 |
| 3. 베타 동안 수동 계좌이체 | 0% | 즉시 | 🟢 단순 | 🟢 우리 |

## 결정

**단계적 채택**:
- **1차 (베타 5곳, 0~6개월)**: 옵션 3 — **수동 계좌이체** (또는 무료 제공)
- **2차 (본격 출시)**: 옵션 2 — **Multiplatform Service 패턴 + 포트원 + 토스페이먼츠 정기결제**
- **IAP는 영구 비채택**

## 인프라 (본격 출시 시)

| 영역 | 선택 |
|---|---|
| 결제 통합·라우팅 | **포트원** (자체 무료 — 월 거래액 5천만원 이하) |
| PG 백엔드 | **토스페이먼츠 자동결제(빌링)** |
| 결제 위치 | 웹 (`billing.on-schedule.kr`) |
| 앱 → 웹 인계 | `expo-web-browser` (SFSafariViewController/Chrome Custom Tabs) |
| 앱 복귀 | `expo-linking` 커스텀 스킴 `onschedule://billing/return` |
| Apple 정책 분류 | Guideline 3.1.3(b) Multiplatform Service |

## 인계 흐름 (코드 레벨)

```
[사장님 앱] 설정 → "구독 관리" 탭
    ↓
POST /api/billing/checkout-session
    ↓ 백엔드가 토스 빌링 페이지 URL + 1회용 세션 토큰 생성
    ↓
expo-web-browser.openAuthSessionAsync(url, "onschedule://billing/return")
    ↓
[SFSafariViewController / Chrome Custom Tabs]
    사장님 카드 등록 → 토스 빌링키 발급 → 우리 백엔드 webhook → DB 저장
    ↓
결제 완료 페이지 → "onschedule://billing/return?status=success" 딥링크
    ↓
[expo-web-browser 자동 dismiss]
    ↓
[앱 복귀] expo-linking 수신 → 백엔드에서 구독 상태 조회 → UI 갱신
```

## 자동 청구 (정기결제) 구현

- `subscription` 테이블: 사장님 ID, 빌링키, 다음 결제일, 플랜
- NestJS Schedule(cron)이 매일 새벽 그 날짜 미결제 구독 조회 → 자동 청구 API
- 결제 성공/실패 webhook → 구독 상태 갱신 + 푸시·알림톡

## Apple 정책 안전 가드

| ❌ 위험 (거부 가능) | 🟢 안전 |
|---|---|
| "지금 구독하기" + 가격 표시 | "구독 관리" |
| "월 5만원 신용카드 결제" | "결제 정보 관리" |
| "웹사이트에서 더 저렴하게" | (외부 가격 비교 일체 금지) |
| 무료 사용자에게 적극 결제 유도 | "프리미엄 기능을 사용하시려면 구독 필요" |

## 근거

- IAP 30% 수수료는 1인 SaaS에 치명적 (월 5만원 구독 100곳 = 월 130만원 손실, 연 1,560만원)
- 한국 사장님은 토스페이/카카오페이/계좌이체에 익숙 — Apple 결제는 어색
- B2B 사업자 카드/통장 사용 → 개인 Apple ID 결제 부적합
- 세금계산서·환불 통제력 = 우리 책임 영역에 둬야 함
- 한국 B2B SaaS의 사실상 표준 (외부 결제)

## 결과

### 베타 단계 운영
- 사장님과 1대1 입금 안내 (월말 알림톡 + 계좌 정보)
- 입금 확인 후 구독 활성 (수동)
- 결제 인프라 구현 0

### 본격 출시 시 구현 항목
- 포트원 + 토스페이먼츠 자동결제 가맹 (포트원 통해 가입비 면제)
- 웹 결제 페이지 (`billing.on-schedule.kr`)
- 사장님 앱 [구독 관리] 탭 → expo-web-browser
- 자동 청구 cron + webhook
- 결제 실패 처리 (ADR-0013 환불 정책 참조)

### 비용
- 포트원 자체: **0원** (월 거래액 5천만원 이하 영구 무료)
- PG 가입비: **0원** (포트원 추천 패키지 → 면제)
- 토스 연회비: 0~11만원/년 (영세 가맹 협상 시 면제·할인)
- 결제 수수료: 거래당 ~2~3% (영세 0.4% 협상 가능)

### 재검토 트리거
- 매장 100곳+ → 결제 안정성·정산 자동화 강화
- IAP 정책 한국 시장 큰 변화 시
- 토스페이먼츠/포트원 정책 큰 변화 시
