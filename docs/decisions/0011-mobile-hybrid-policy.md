# ADR-0011: 모바일 앱 — 부분 하이브리드 정책 (Expo + 선택적 WebView)

상태: 채택
일자: 2026-05-03

## 컨텍스트

ADR-0002에서 사장님 앱 = Expo 네이티브로 결정했다. 그러나 일부 화면(결제 위젯, 정적 법적 문서, 콘텐츠성 페이지)은 네이티브로 만들 가치가 적거나 오히려 웹뷰가 더 적합하다.

"하이브리드 앱"은 한 가지 모델이 아니라 스펙트럼이다:
- 풀 네이티브 (Expo, RN)
- 부분 하이브리드 (네이티브 + 일부 WebView)
- 풀 웹뷰 컨테이너 (Capacitor, Cordova)
- PWA (앱 아님)

어디까지 하이브리드를 허용할지 정책으로 못박지 않으면, 시간 압박 시 핵심 도메인 화면까지 웹뷰로 만들고 싶은 유혹이 생긴다.

제약:
- 1인 운영 — 두 스택 동시 운영 부담 회피
- iOS 심사 정책: 풀 웹뷰 앱은 거부 위험 (Guideline 4.2)
- Expo는 이미 EAS Update(OTA)로 JS 코드 재심사 우회 가능 → 풀 웹뷰의 가장 큰 매력 무력화
- 사장님은 매일 사용 → 네이티브 UX 가치 큼

## 검토한 옵션

| 옵션 | 푸시 신뢰성 | iOS 심사 | 1인 부담 | 빠른 업데이트 |
|---|---|---|---|---|
| 풀 네이티브 | 🟢 | 🟢 | 🟢 | 🟢 EAS Update |
| **부분 하이브리드** | 🟢 | 🟢 | 🟢 | 🟢 EAS Update + 웹 즉시 배포 |
| 풀 웹뷰 컨테이너 | 🟡 플러그인 | 🔴 거부 위험 | 🟠 두 스택 | 🟢 |
| PWA | 🔴 iOS 푸시 약함 | - | 🟢 | 🟢 |

## 결정

**부분 하이브리드 채택.** Expo 네이티브가 디폴트이며, 다음 4가지 케이스에 한해 `react-native-webview` 임베드 또는 `expo-web-browser` 외부 인계를 허용한다.

### 허용 케이스
| # | 케이스 | 방식 |
|---|---|---|
| 1 | **결제 위젯** (PG SDK는 웹 기준) | `expo-web-browser` (외부 SFSafariViewController/Chrome Custom Tabs) |
| 2 | **정적 법적 문서** (이용약관, 개인정보 처리방침) | `react-native-webview` 또는 외부 브라우저 |
| 3 | **콘텐츠성 페이지** (공지사항, 가이드, FAQ) | `react-native-webview` |
| 4 | **임시 실험 화면** (베타 기능 빠른 검증) | `react-native-webview` (PMF 후 네이티브로 전환) |

### 금지 케이스
- 핵심 도메인 화면(예약 목록·확정/거절·메뉴 관리·매장 설정)은 **웹뷰 금지**
- 푸시 알림 수신 후 이동하는 화면은 네이티브 (반응 속도 + 안정성)
- 시스템 권한 접근(카메라, 위치, 알림 설정) 화면은 네이티브

## 근거

- "심사 우회"는 Expo OTA로 이미 해결 → 풀 웹뷰 정당화 사라짐
- 결제 위젯·법적 문서·콘텐츠는 웹과 100% 동일하므로 코드 중복 회피 가치 큼
- iOS Guideline 4.2 위반 위험 회피 (풀 웹뷰 앱 거부)
- 1인 운영에 두 스택(웹+네이티브 셸) 동시 운영은 부담

## 결과

### 구현 항목
- `expo-web-browser` (인앱 브라우저 + 딥링크 자동 dismiss)
- `expo-linking` (커스텀 스킴 `onschedule://`)
- `react-native-webview` (임베드용)
- 정적 페이지(약관, 처리방침)는 웹 코드베이스 한 번에 작성 → 양쪽 재사용

### 탭 네비게이션 (네이티브 도메인 화면)
- **Native Tabs 사용**: `expo-router/unstable-native-tabs`
  - iOS: UITabBarController (Liquid Glass on iOS 26)
  - Android: BottomNavigationView (Material 3)
- **브랜드 색 보정**:
  - tintColor: `#5B3A24` (브랜드 카라멜)
  - Android 인디케이터: `#F2C794` (캐러멜 소프트, M3 알약 인디케이터의 시각 노이즈 완화)
  - elevation 0 + hairline border로 평면 미니멀
- **한글 라벨은 2글자 제한** ("예약", "고객", "설정") — iOS 잘림 방지

### 금지 케이스에 추가
- 🚫 알림 액션 버튼이 발동하는 화면 → 무조건 네이티브
- 🚫 Widget 데이터 표시 화면 → 네이티브 (Widget이 native라 동기화)
- 🚫 CallKit 발신자 표시가 매핑하는 손님 카드 → 네이티브 (Phase 3 도입 시)

### 카피·UX 가이드
- 웹뷰 화면은 헤더에 "웹뷰" 표시 X (사장님이 인지할 필요 없음)
- 외부 브라우저 인계 시 "잠시 사이트로 이동합니다" 안내 1초

### 재검토 트리거
- iOS PWA 푸시 정책이 크게 개선되면 PWA 모델 검토
- 핵심 도메인 화면을 웹뷰로 만들고 싶은 유혹이 생기면 이 ADR을 다시 읽기
- NativeTabs API가 stable로 승격되면 import 경로 갱신 (`unstable-native-tabs` → 정식)
