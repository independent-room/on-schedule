## 상태 정의

- **잠정**: 결정했지만 검증/PoC 후 변경 가능성 명시
- **채택**: 코드/문서/계약에 반영된 활성 결정
- **폐기**: 더 이상 적용되지 않음 (사유 기록)
- **대체됨**: 후속 ADR로 갱신됨 (대체 ADR 번호 명시)

## 템플릿

```markdown
# ADR-NNNN: 제목

상태: 잠정 | 채택 | 폐기 | 대체됨(→ ADR-XXXX)
일자: YYYY-MM-DD

## 컨텍스트
무엇이 문제였나, 어떤 제약이 있었나

## 검토한 옵션
A / B / C ... (장단점)

## 결정
무엇을 골랐나

## 근거
왜 이걸 골랐나 (핵심 트레이드오프)

## 결과
이 결정이 가져올 영향, 추후 재검토 트리거
```

## 작성 규칙

- 결정이 바뀌면 새 ADR을 쓰고 기존 ADR의 상태를 "대체됨"으로 변경한다 (덮어쓰지 않는다)
- "왜"를 1문단 이상 적는다 — 6개월 후의 본인이 가장 궁금해할 부분
- "재검토 트리거"를 명시한다 — 어떤 데이터/사건이 발생하면 다시 본다
