# 유저 획득 전략

## 단기: 랜딩페이지 검증 광고 (월 10~20만원)

### 목표

서비스 출시 전 랜딩페이지로 사전 신청을 받아 고객 관심을 정량 검증한다.

### 예산 전략: 단계적 투자

- 월 최대 20만원
- 1개월차 10만원으로 메시지/채널 검증 → 결과 보고 2개월차 배분 결정

### 1개월차: 10만원 배분

| 채널 | 예산 | 목적 | 기대 효과 |
|------|------|------|----------|
| 인스타그램 광고 | 5만원 | 유입량 테스트 — 어떤 메시지에 클릭하는지 확인 | CPC 300~500원 기준 100~170명 유입 |
| 네이버 검색광고 | 3만원 | 전환 테스트 — "예약 관리", "노쇼 방지" 키워드 | 검색 의도가 명확한 사장님 유입 |
| 네이버 블로그 | 무료 | 검색 유입 누적 — "베이커리 노쇼 해결법" 등 3~5개 글 | 2~4주 후 자연 검색 유입 시작 |
| 네이버 카페 | 무료 | "아프니까 사장이다"(151만명) 리서치형 게시글 | 무료 노출, 홍보 반감 주의 |
| 예비 | 2만원 | 소재 변경 후 재테스트용 | - |

### 채널별 역할

| 채널 | 성격 | 유입 타입 |
|------|------|----------|
| 인스타 광고 | "이런 문제 있으시죠?" — 문제 인지 | 볼륨 (양) |
| 네이버 검색광고 | "예약 관리 프로그램" 검색 — 이미 니즈 있음 | 전환 (질) |
| 네이버 블로그 | 검색 SEO — 누적 자산 | 장기 유입 |
| 네이버 카페 | 커뮤니티 신뢰 — 리서치/후기 형태 | 보조 |

### 인스타 광고 상세

- 타겟팅: 소상공인 / 베이커리 / 자영업자 / 카페 관심사
- 소재: 사장님 페인포인트 공감형 ("DM으로 예약 받다가 또 빠뜨리셨죠?")
- CTA: 랜딩페이지 → 사전 신청
- 소재 A/B 테스트: 2~3개 소재 돌려서 CTR 비교

### 네이버 검색광고 상세

- 키워드 후보: "예약 관리 프로그램", "노쇼 방지", "베이커리 예약 시스템", "알림톡 예약", "예약 관리 앱"
- CPC: 300~1,000원 예상 (B2B SaaS 키워드는 경쟁 낮음)
- 주의: 검색량 자체가 적을 수 있음 → 3만원 예산이면 충분히 테스트 가능

### 네이버 블로그 상세

- 주제: "베이커리 노쇼, 사장님들은 어떻게 해결하고 있을까", "카톡 예약 관리의 한계", "네이버 예약 vs 독립 예약 링크"
- 3~5개 글 발행 → 검색 유입 누적
- 글 하단에 랜딩페이지 링크

### 1개월차 성공 기준

| 지표 | 기준 |
|------|------|
| 랜딩페이지 방문자 | 200명 이상 |
| 사전 신청 전환율 | 5% 이상 (10명+) |
| 채널별 전환율 비교 | 어떤 채널이 더 효과적인지 판단 가능 |

### 2개월차 판단 기준

| 1개월차 결과 | 2개월차 행동 | 예산 |
|-------------|-------------|------|
| 인스타 전환율 > 네이버 | 인스타에 집중 | 15만원 인스타 + 5만원 기타 |
| 네이버 전환율 > 인스타 | 네이버 검색 + 블로그 강화 | 10만원 검색 + 블로그 강화 |
| 둘 다 반응 없음 | 메시지 피벗 — 가치 제안이나 타겟이 틀린 것 | 추가 투자 보류 |
| 둘 다 반응 좋음 | 반반 유지 | 10만원씩 |

## 중장기: 뉴스레터 GTM

서비스 기능이 아닌 고객 획득 채널.
사장님들의 신뢰를 쌓고 유료 전환으로 연결하는 퍼널.

```text
뉴스레터 구독 (무료) -> 신뢰/커뮤니티 구축 -> 예약 SaaS 베타 초대 -> 유료 전환
```

### 콘텐츠 방향

- 전세계 베이커리 시장 소식 큐레이션 (트렌드, 원재료 시세, 성공/실패 사례)
- 사장님이 바로 써먹을 수 있는 인사이트 ("이번 주 일본에서 뜬 디저트" 등)
- 트렌드 레시피 가이드: "뜨는 이유 + 만드는 법" 세트로 제공

AI로 트렌드 감지 + 레시피 초안 생성 -> 검수 후 발송. 레시피 정확도가 신뢰에 직결되므로 AI 단독 발행 금지.

### 소싱 방법

| 소스 | 언어 | 내용 |
|------|------|------|
| Bake Magazine | 영어 | 글로벌 제빵 업계 뉴스 |
| Modern Baking | 영어 | 미국 베이커리 트렌드 |
| British Baker | 영어 | 유럽 베이커리 시장 |
| 일본 제과제빵 매체 | 일어 | 아시아 트렌드 |
| 국내 식품 뉴스 | 한국어 | 원재료, 규제, 업계 동향 |

### 수익화 경로

| 단계 | 활동 | 목표 |
|------|------|------|
| 1단계 | 뉴스레터 무료 발행 (주 1회) | 구독자 500명 |
| 2단계 | 커뮤니티 형성 (카톡 오픈채팅 등) | 사장님 네트워크 |
| 3단계 | 예약 SaaS 베타 초대 | 무료 사용자 확보 |
| 4단계 | 유료 전환 | 월 구독 14,900~19,900원 |

### 뉴스레터 시작 시점

단기 광고 검증(랜딩페이지 테스트)에서 관심이 확인된 후 시작. 검증 전에 뉴스레터부터 시작하면 구독자 모으는 데만 시간을 쓰고 서비스 개발이 늦어짐.

## 기타 획득 채널

가설 검증(04.고객발견.md)에서 접촉한 사장님들이 뉴스레터 초기 구독자 + 베타 사용자가 될 수 있음.

- 주변 자영업자 심층 인터뷰 대상 (3~5명)
- 인스타/네이버 광고를 통한 사전 신청자
- 커뮤니티 (아프니까 사장이다, 장사의신) 접촉 사장님들
