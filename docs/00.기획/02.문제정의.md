# 문제 정의

## 누가 어떤 불편을 겪는가

소규모 베이커리/디저트 사장님들이 카톡 DM/인스타 DM으로 예약을 관리하면서 다음 문제를 겪고 있다:

- 주문 누락
- 노쇼 (예약 부도)
- 수동 알림 (확정/리마인드를 일일이 보내야 함)
- 중복 예약 (일일 생산량 초과)

## 노쇼 현황 데이터 (2025~2026)

| 지표 | 수치 | 출처 |
|---|---|---|
| 외식업 노쇼 피해 경험률 | 65% (최근 3년) | 한국경제 2026.01 |
| 피해 점포당 평균 횟수 | 3년간 8.6회 | 한국경제 2026.01 |
| 1회당 평균 손실액 | 44.3만원 | 한국경제 2026.01 |
| 예약보증금 설정 비율 | 14%에 불과 | 한국경제 2026.01 |
| 커피전문점 노쇼 횟수 | 13.5회 (업종 2위) | 서울경제 |
| 노쇼 사기 피해 (2025 1~9월) | 4,506건, 737억원 | 한국경제 2025.11 |

**핵심 시사점**: 노쇼는 여전히 심각하고, 예약보증금을 설정한 곳이 14%밖에 안 됨 = **도구가 없어서 못하고 있다는 신호.**

## 기존 대안이 불충분한 이유

### 네이버 예약의 한계

> 2026-04-10 재검증 완료. 기존 "자동 확정 거절 불가", "CRM 없음"은 사실과 다름. 아래 수정 반영.

| 한계점 | 영향 | 검증 상태 |
|---|---|---|
| 결제 수수료 3.74% | 월 매출 500만원 기준 약 18.7만원 부담 | 확인됨 |
| ~~자동 확정 (거절 불가)~~ → **자동/수동 확정 선택 가능** | 네이버 자체는 "담당자 확인 후 확정" 선택 가능. **단, 외부 서비스(공비서 등) 연동 시 자동 확정만 가능** | 수정됨 (공비서 가이드 출처) |
| 시간 설정 제한 (30분/1시간만 가능) | 10분/15분 등 커스텀 불가. 변경 시 예약 삭제 후 재생성 필요. 베이커리 픽업 시간 유연성 부족 | 확인됨 |
| 중복 예약 발생 | 일일 생산량 제한 기능 없음 → 초과 주문 가능 | 확인됨 |
| ~~CRM 없음~~ → **기본 고객관리는 있으나 제한적** | 방문이력, 결제금액, 재방문주기 조회 가능. **노쇼 이력 추적, 세그먼트 분류, 마케팅 자동화, 고객 병합은 없음** | 수정됨 |
| 온보딩 복잡 | 파트너센터 가입 → 사업자등록증 → 네이버페이 → 계좌 → 메뉴 등록. 바쁜 사장님에게 부담 | 추가됨 |

### 한국 경쟁 서비스 현황

베이커리/디저트 특화 예약 SaaS는 한국에 존재하지 않는다. 캐치테이블(레스토랑), 콜라보살롱(뷰티) 등은 업종이 다르다.

## Vitamin vs Painkiller vs Antibiotic

**Painkiller**에 해당한다.

- 노쇼 1건당 평균 44.3만원 손실은 실질적 금전 피해
- DM 기반 수동 관리는 매일 반복되는 운영 부담
- "있으면 좋은" 수준이 아니라 "없으면 돈을 잃는" 수준

## 가설 vs 검증 상태

| 가설 | 검증 상태 | 근거 |
|---|---|---|
| 베이커리 사장님들이 예약/노쇼 문제를 겪고 있다 | 부분 검증 | 지금예약 경험 + 노쇼 통계 |
| 네이버 예약이 니즈를 충분히 해결하지 못한다 | 부분 검증 | 알려진 한계점 (직접 인터뷰 미실시) |
| 월 3~5만원 지불 의향이 있다 | 부분 검증 | 지금예약에서 유료 사용자 존재 |
| 1인 운영이 가능하다 | 미검증 | 개발 과정에서 검증 필요 |
