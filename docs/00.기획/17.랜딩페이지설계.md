# 랜딩페이지 설계서

사전 신청(Waitlist) 목적의 원페이지 랜딩페이지 설계.
**톤앤매너 레퍼런스: 콜라보살롱** (https://www.colavo.kr/) — 친근한 공감 질문형, 문제→해결 구조.

## 목적

- 광고(인스타/네이버) 유입 → 사전 신청 전환
- 신청자를 인터뷰 대상으로 자연 전환 (Waitlist-to-Interview 퍼널)
- 메시지·타겟·가격 가정 검증

## 페이지 구성

| 유형 | 페이지 | 목적 |
|------|--------|------|
| 메인 | 원페이지 랜딩 (index) | 사전 신청 전환 |
| 분리 | 사전 신청 완료 페이지 | 감사 + 인터뷰 요청, Meta Lead 이벤트 발동 |
| 분리 | 개인정보처리방침 | PIPA 필수, 네이버 광고 심사 필수 |
| 분리 | 이용약관 | 사전 신청 시 동의 |

### 네비게이션

- 최소화: 로고 + "사전 신청" 앵커 버튼만
- 글로벌 메뉴 없음 (전환 이탈 방지)

## 콜라보살롱 톤 핵심 패턴

| 패턴 | 예시 |
|------|------|
| 공감형 질문 | "여기저기 따로 받은 고객, 번거롭죠?" |
| 문제→해결 구조 | "시술하랴, 안내하랴 바쁘신가요?" → "원장님을 대신하는 카톡 알림" |
| 포괄성 표현 | "1인샵부터 10인샵 이상까지" |
| 친근한 존댓말 | "~세요", "~죠?" |
| 장벽 제거 단정 | "결제수단 NO! 전화 상담 NO!" |
| CTA 심플 | "자세히 보기 ⇒" |

→ 본인 서비스에 그대로 차용. "원장님" → **"사장님"**, 뷰티 한정 → **자영업 전반**.

## 섹션별 설계

### 1. 헤더 (Sticky)

```
[로고]                              [사전 신청 ⇒]
```

- 스크롤 시 상단 고정
- CTA 버튼 계속 노출

### 2. 히어로 섹션

```
[H1]
예약 받기, 알림 보내기, 고객 관리까지
모두 한 곳에

[서브]
사장님이 가장 쉽게 만드는 예약 시스템

[본문]
여기저기 흩어진 예약을 한 곳에서 관리하고
사장님 시간을 돌려드립니다

[CTA]
사전 신청 ⇒

[CTA 보조]
선착순 100명 · 이메일만 입력 · 30초

[혜택 칩]
✓ 출시 후 3개월 무료
✓ 오픈 전 미리 사용
✓ 평생 회원가 보장
```

**시각 자산:**
- 우측 또는 하단에 목업 이미지 (스마트폰 + 대시보드)
- 카톡·인스타·네이버 톡톡 등 다양한 채널이 한 곳으로 모이는 시각화
- 톤은 깔끔·친근

### 3. 가치 선언 섹션

```
[H]
온스케줄로 사장님의 든든한 운영을 돕겠습니다

[본문]
예약 받기부터 알림톡 발송, 고객 관리까지
사장님 가게 운영을 전반적으로 지원합니다

[수치 카드 3개]
✓ 5분 만에 셋팅 완료
✓ 알림톡 무제한
✓ 사용량 제한 없음
```

→ 콜라보살롱 "단단한 성장을 돕겠습니다" 패턴 그대로.

### 4. 핵심 기능 5개 (콜라보살롱 패턴)

각 기능마다 **공감 질문 → 기능명 → 한 줄 설명** 구조.

#### 기능 1
```
매번 카톡, 인스타, 톡톡 답장 다니시나요?

샵 전용 예약 링크
링크 하나로 언제 어디서든
고객이 알아서 예약 가능
```

#### 기능 2
```
예약 셋팅, 어디서부터 시작해야 할지 막막하신가요?

단계별 셋업
메뉴, 시간, 결제, 알림까지
순서대로 5분이면 끝
```

#### 기능 3
```
예약 알림 매번 직접 보내시나요?

자동 알림톡
사장님을 대신하는
똑똑한 카톡 알림
```

#### 기능 4
```
노쇼로 매출 새는 거, 이제 그만하고 싶으시죠?

노쇼 자동 관리
단계별로 자동 처리하고
반복 노쇼는 차단까지
```

#### 기능 5
```
단골 고객을 더 챙기고 싶으신가요?

자동 고객 관리
방문 이력부터 단골 표시까지
사장님 대신 기억해드립니다
```

**MVP/v2 배지:**
- 1, 3, 4: MVP
- 2: MVP (셋업 위저드 핵심)
- 5: v2

### 6. 진입장벽 제거 섹션 (콜라보살롱 형식)

### 7. 창업자 스토리 섹션 (신뢰 구축)

정식 서비스의 고객 후기 자리를 **창업자 경험**으로 대체.

```
[H]
예약 SaaS를 운영하며 직접 본 문제,
이번엔 다르게 풀어봅니다.

[본문]
지금예약을 운영하던 시절,
사장님들이 가장 답답해하시던 건
'예약 도구가 너무 많고 복잡하다'였습니다.

이번엔 1인 부트스트랩으로 다시 시작합니다.
채널톡 + 예약 + CRM을 하나로,
사장님이 5분 만에 셋팅할 수 있게.
```

### 10. FAQ 섹션

```
[H]
궁금한 점 있으세요?
```

| Q | A |
|---|---|
| 출시는 언제예요? | 2026 OO월 MVP 출시 예정. 사전 신청자는 1순위로 초대해드립니다. |
| 사전 신청하면 뭐가 달라져요? | 출시 후 3개월 무료, 오픈 전 미리 사용, 평생 회원가 보장 받습니다. |
| 지금 돈 내는 건가요? | 아닙니다. 출시 후 유료 전환 시에만 과금됩니다. 이메일만 남겨주세요. |
| 셋팅이 어렵지 않나요? | 단계별로 진행하시면 됩니다. 메뉴·시간·결제·알림까지 5분이면 끝납니다. |
| 알림톡 진짜 무제한인가요? | 예약 관련 알림(확정/리마인드/완료)은 무제한 포함. 마케팅 메시지는 별도. |

| 개인정보는 안전한가요? | PIPA 준수. 이메일은 출시 알림 및 얼리버드 혜택 안내에만 사용합니다. |

- 아코디언 형식
- 셋업 관련 질문 추가 (단계별 셋업 강조)

## 디자인 방향

### 디자인 시스템 (ADR-0016 — Wanted DS 기반 + 베이커리 캐러멜 톤)

| 항목 | 적용 |
|------|------|
| **베이스** | Wanted Design System |
| **브랜드 컬러** | 캐러멜 #E8761A (베이커리 따뜻함) |
| **폰트 — 본문** | Pretendard JP |
| **폰트 — 디스플레이/숫자** | Wanted Sans |
| **폰트 — 코드** | JetBrains Mono |
| **아이콘** | Lucide Icons (24px, stroke 1.75) |
| **CSS 토큰** | `docs/design/project/colors_and_type.css` 참조 |

### 카피 톤앤매너

- **레퍼런스**: 콜라보살롱 (친근한 공감 질문형) + 토스 (깔끔, 여백)
- 카피 패턴: 공감 질문 → 기능명 → 한 줄 설명
- "사장님" 호칭 (자영업 전반)

→ **디자인 시스템(Wanted DS + 캐러멜)과 카피 톤(콜라보살롱)은 다른 레이어로 양립.**

### 시각 자산

- 목업: Nano Banana Pro 또는 Microsoft Designer로 생성
- 아이콘: Lucide Icons (디자인 시스템 표준)
- 카톡·인스타·네이버 톡톡 → 한 곳으로 모이는 통합 시각화
- 기존 디자인 자산: `docs/design/project/landing/` 활용 가능

### 모바일 최적화

- 모바일 퍼스트 (타겟 사장님 70%+ 모바일 방문)
- CTA 버튼: 엄지 도달 범위 내
- 텍스트 최소 16px

## 제작 방법

### 1단계: 디자인 레퍼런스 (Nano Banana Pro / Microsoft Designer, 무료)

콜라보살롱 톤 참고 + 본인 차별점 반영. 목업 이미지 3~5장 생성.

### 2단계: 코드 생성 (v0.dev 추천)

- v0.dev에 콜라보살롱 톤 + 본인 카피 입력 → 풀 페이지 생성
- React + Tailwind 코드 한방에

### 3단계: 배포

- Vercel 또는 Netlify 무료 플랜
- 도메인: onschedule.kr
- HTTPS 자동

### 4단계: 테스트

- 모바일/데스크톱 반응형 확인
- 폼 제출 → Thank You 페이지 이동 확인
- Meta Pixel Helper로 이벤트 발동 확인
- 네이버 로그 분석 확인
