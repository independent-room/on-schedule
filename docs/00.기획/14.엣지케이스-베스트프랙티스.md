# 엣지 케이스별 Best Practice

경쟁사 조사(2026-04-10) 결과 기반. 53건 각 케이스별로 가장 잘 대응하고 있는 서비스를 지정하고, 본 서비스 적용 방안을 정리한다.

---

## A. 입력 오류

| # | 케이스 | Best Practice | 이유 | 본 서비스 적용 |
|---|--------|--------------|------|--------------|
| 1~2 | 전화번호 형식/정규화 | 업계 공통 | 차별화 없음 | 11자리 정규식 검증 + 자동 정규화 |
| 3~4 | 안심번호/국가번호 | **솔라피** | 안심번호 수신 불가를 가장 명확하게 문서화 | 050 감지 차단 + +82 자동 변환 |
| 5~6 | 이름 검증 | 업계 공통 | 차별화 없음 | 특수문자 필터 + 공백 차단 |
| 7~8 | 날짜/영업시간 | **Calendly** | 선택기 비활성화 UX가 가장 깔끔 | 과거 날짜/영업외 시간 비활성화 |
| 9 | 수량 제한 | 없음 | **경쟁사 중 이 기능 보유 0곳. 본 서비스 차별점** | 메뉴별 일일 최대 수량 설정 → 초과 시 자동 마감 |
| 10 | 필수값 검증 | 업계 공통 | 차별화 없음 | 메뉴/시간 미선택 시 제출 차단 |

## B. 중복/재예약

| # | 케이스 | Best Practice | 이유 | 본 서비스 적용 |
|---|--------|--------------|------|--------------|
| 11 | 재예약 시 기존 고객 인식 | **팅커뷰** | 전화번호 기반 자동 인식 + 이력 누적이 가장 체계적 | 전화번호로 기존 프로필 자동 매칭, 방문 횟수 +1 |
| 12 | 동일 날짜/시간 중복 | **Calendly** | "이미 예약됨" 처리가 가장 직관적 | "이미 예약이 있습니다. 수정하시겠어요?" |
| 13 | 이름 오타 감지 | **핸드SOS** | "이름 + 뒷자리" 휴리스틱. 유일한 자동 감지 | 전화번호 동일 + 이름 다름 → "○○님 맞으신가요?" |
| 14 | 마케팅 동의 상태 유지 | **채널톡** | 빌더사 연동 시 동의 상태 자동 동기화 | DB 저장 상태 불러와 자동 반영 |

| 18 | 마케팅 거부 고객 제외 | **채널톡** | 광고성 체크 시 수신거부 고객 자동 제외 + 하단 링크 자동 삽입 | 발송 큐에서 미동의 고객 자동 제외 |

| 20 | 수신거부 즉시 처리 | **스티비** | 원클릭 수신거부 + 처리결과 즉시 표시 + "다시 구독하기" | 링크 클릭 → 즉시 DB 반영 + 큐 중단 |
| 21 | 발신프로필 휴면 경고 | **식스샵** | "휴면 해제하기" 1클릭 복구 UI | v2: 150일 경과 시 사장님 알림 |
| 22 | 템플릿 휴면 경고 | **식스샵** | 동일 | v2: 300일 경과 시 사장님 알림 |
