# 가치 제안 정의

## 한 문장 가치 제안

**"채널톡 + 예약 시스템 + CRM을 소상공인 가격에 하나로"**

## 왜 이 서비스를 써야 하는가

현재 사장님이 예약관리 + 고객 문의 응대 + 고객관리를 하려면 3개 서비스를 써야 하고 월 9만원 이상 든다. 이 서비스는 그걸 하나로 합쳐서 19,900원에 제공한다.

## 핵심 차별점 우선순위

1. **예약 + CS + CRM 통합** — 3개 서비스를 1개로
2. **단계별 셋업 위저드** — 메뉴·시간·결제·알림 5분 셋팅, 빈 화면 공포증 X
3. **알림톡 무제한 포함** — 별도 충전/과금 없음
4. **AI 챗봇 (RAG)** — 사장님 가게 정책 기반 자동 CS
5. **일일 수량 제한** — 베이커리/디저트 생산량 관리 (경쟁사에 없는 기능)
6. **범용 시스템** — 뷰티에 묶이지 않고 어떤 업종이든 사용 가능 (시간 처리 5패턴 지원)
