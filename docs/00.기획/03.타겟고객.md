# 타겟 고객 정의

## 초기 타겟 페르소나

### 1순위: 소규모 오프라인 베이커리/디저트 사장님

| 항목 | 내용 |
|------|------|
| 업종 | 베이커리 / 디저트 (오프라인 매장 보유) |
| 규모 | 사장님 본인 + 직원 0~2명 |
| 월 매출 | 500만원 이하가 다수, 일부 대형 매장은 그 이상 |
| 예약 방식 | 카톡 DM + 인스타 DM + 네이버 톡톡 혼용 (전화 예약은 가장 적음) |
| 디지털 리터러시 | 중하 — 셋팅이 복잡하면 이탈. 선형 온보딩(배민 방식) 필수 |
| 예약 확인 시간대 | 영업시간 내 수시 확인, 밤에는 거의 없음 |
| 핵심 페인포인트 | 노쇼, 주문 누락, 수동 알림, 중복 예약, 일일 생산량 초과 |
| 현재 도구 비용 감당 능력 | 월 94,500원(채널톡+팅커뷰)은 부담 → 14,900원은 부담 없음 |

### 제외 대상

| 유형 | 제외 이유 |
|------|----------|
| 홈베이킹 (매장 없음) | 지금예약 경험상 유료 전환자 중 홈베이킹 없었음 |
| 대형 프랜차이즈 | 이미 자체 시스템 보유, 타겟 아님 |
| 레스토랑/카페 | 캐치테이블 등 기존 솔루션 존재 |

## 확장 타겟 (2순위)

지금예약 때 유료 전환이 확인된 업종. 시스템은 범용이므로 마케팅만 확장하면 됨.

| 업종 | 근거 |
|------|------|
| 뷰티 (타투/반영구/네일) | 지금예약 유료 사용자 존재 |
| 원데이클래스 | 지금예약 유료 사용자 존재 |

## 세그먼트 우선순위

1. **베이커리/디저트** — 지금예약 때 비율 가장 높았고, 특화 경쟁사 0개
2. **뷰티** — 경쟁사 있으나(공비서, 콜라보살롱, 팅커뷰) 예약+챗봇 통합은 없음
3. **원데이클래스** — 시장 작지만 예약 니즈 명확

## 공통 특성

- 작은 단위의 업장을 운영하는 자영업자
- 다채널 예약 관리(인스타+카톡+네이버) 혼용으로 인한 운영 부담
- 도구 비용에 민감 (월 매출 대비 SaaS 비용 비율 중요)
- 셋팅 복잡도에 민감 — Feature Creep/Branching Complexity가 발생하면 온보딩 실패

## 온보딩 레퍼런스

배달의민족 세팅 프로세스 — 선형 온보딩(Linear Onboarding). 선택지를 최소화하고 단계별로 하나씩만 묻는 방식. 지금예약에서 이 방식 적용 후 CS 감소 및 호전 확인됨.
