# 인스타그램 광고 실행 가이드

12.유저획득전략의 "인스타 광고 5만원" 실행을 위한 A to Z 가이드.

## 전체 흐름

```text
페이스북 페이지 생성
  → 비즈니스 포트폴리오(비즈니스 매니저) 생성
    → 인스타그램 프로페셔널 계정 연동
      → 광고 계정 생성 + 결제수단 등록
        → Meta 픽셀 설치 (랜딩페이지에 코드 삽입)
          → Conversions API 1-Click 설정 (2026-04 신규)
            → 광고 소재 제작
              → 광고 캠페인 생성/발행
                → 성과 모니터링
```

---

## STEP 1. 페이스북 페이지 생성

Meta 광고는 **페이스북 페이지가 반드시 있어야** 집행 가능. 인스타그램만 쓸 거라도 필수.

### 실행 절차

1. `facebook.com/pages/create` 접속
2. 페이지 이름 = 서비스명 (예: 예약 SaaS 이름)
3. 카테고리: "소프트웨어" 또는 "비즈니스 서비스"
4. 프로필 사진 + 커버 이미지 등록

### 체크 포인트

- 페이지 이름은 나중에 변경 가능하지만, URL은 생성 후 변경 어려움
- 카테고리는 광고 타겟팅과 무관하지만 사용자 신뢰도에 영향

---

## STEP 2. 비즈니스 포트폴리오(비즈니스 매니저) 생성

`business.facebook.com`에서 생성. 페이지 + 광고 계정 + 픽셀 + 직원 권한을 한 곳에서 관리하는 허브.

### 실행 절차

1. `business.facebook.com` 접속
2. "비즈니스 만들기" 클릭
3. 비즈니스 이름 (사업자명) 입력
4. 이메일 입력
5. 사업자등록번호 등록 (세금계산서 발행 시 필요)
6. STEP 1에서 만든 페이스북 페이지 연결

### 체크 포인트

- 개인사업자 등록증 기반으로 세금계산서 수령 가능
- 비즈니스 인증(Business Verification)은 선택이지만, 인증하면 광고 한도 상향

---

## STEP 3. 인스타그램 프로페셔널 계정 연동

### 실행 절차

1. 인스타 앱 → 설정 → 계정 → **프로페셔널 계정으로 전환**
2. 비즈니스 또는 크리에이터 중 선택 (광고는 비즈니스 권장)
3. 페이스북 페이지와 연결 (STEP 1에서 만든 페이지)
4. 비즈니스 포트폴리오 > 계정 > 인스타그램 > 추가

### 체크 포인트

- 이 단계 안 하면 인스타 광고에 **페이스북 프로필이 노출**돼서 어색함
- 프로페셔널 계정 전환은 무료, 언제든 개인 계정으로 되돌릴 수 있음

---

## STEP 4. 광고 계정 생성 + 결제수단 등록

### 실행 절차

1. 비즈니스 포트폴리오 > 광고 계정 > 새 계정 추가
2. 계정 이름 설정
3. 통화: **KRW** (한화로 결제)
4. 시간대: **서울**
5. 결제수단 등록 (신용카드/체크카드)
6. 개인사업자 정보 입력 (세금계산서 수령 시)

### 체크 포인트

- 초기엔 결제 한도가 낮음 (일 5~10만원 수준), 결제 이력 쌓이면 상향
- 통화·시간대는 **생성 후 변경 불가**

---

## STEP 5. Meta 픽셀 설치

픽셀 = 랜딩페이지에 심는 추적 코드. **안 심으면 전환율 측정 불가**하고 광고 최적화가 안 됨.

### 실행 절차

1. 광고 관리자 > 이벤트 관리자 > 데이터 연결
2. "웹(Web)" 선택 → 새 픽셀 생성
3. 픽셀 이름 지정
4. Pixel ID 발급 (숫자 15자리)
5. 랜딩페이지 `<head>` 태그에 스크립트 코드 삽입
6. 이벤트 추가: **"Lead"** (사전 신청 완료 시 발동)

### 추적할 이벤트

| 이벤트 | 발동 시점 | 용도 |
|--------|----------|------|
| PageView | 랜딩 방문 | 유입 측정 |
| **Lead** | 사전 신청 제출 | **전환 측정 (핵심)** |

### 체크 포인트

- Claude로 랜딩페이지 만들 때 픽셀 코드 삽입까지 한 번에 요청
- 2026-04 이후 Pixel에 AI 자동 데이터 보강 기능이 기본 ON (Events Manager에서 확인)
- 설치 확인은 Chrome 확장 "Meta Pixel Helper"로 가능

---

## STEP 6. Conversions API (CAPI) 설정

2026-04-15 이후 **1-Click 설정 기능 도입**. 브라우저 쿠키 차단을 우회하는 서버→서버 전송 방식.

### 왜 필요한가

- iOS 추적 제한, 브라우저 쿠키 차단으로 **Pixel 단독 추적은 데이터 누락 많음**
- CAPI 사용 시 결과당 비용 **평균 17.8% 절감** (Meta 공식 데이터)

### 실행 절차

1. 이벤트 관리자 > 데이터 소스 > Conversions API
2. "간편 설정(Meta-enabled)" 선택
3. 원클릭으로 활성화
4. Pixel과 동일한 이벤트(Lead, PageView) 선택

### 체크 포인트

- 기존엔 개발자 작업이 필요했지만 이제 무료, 원클릭, 유지보수 불필요
- Pixel + CAPI 둘 다 설정하는 게 표준

---

## STEP 7. 광고 소재 제작

### 규격

| 포맷 | 사이즈 | 추천 |
|------|-------|------|
| 피드 | 1:1 (1080×1080) 또는 4:5 (1080×1350) | 기본 |
| **릴스/스토리** | 9:16 (1080×1920) | **최우선 — 2026년 릴스 참여율 30% 높음** |

### 메시지 원칙

- 첫 3초 훅: 스크롤 멈추게 하는 문구 (예: "DM으로 예약 받다가 또 빠뜨리셨죠?")
- 문제 공감 → 해결책 제시 → CTA 구조
- 자동 자막 켜기 (알고리즘이 선호)
- CTA는 마지막 3초에 배치

### 소재 개수

**최소 2~3개** 만들어서 A/B 테스트. 2주 이상 같은 소재 돌리면 CTR 40% 하락.

### 체크 포인트

- 동영상이 부담되면 **카루셀(여러 이미지) 광고**로 시작 가능
- Meta Advantage+ Creative 기능으로 AI가 자동 변형 버전 생성

---

## STEP 8. 캠페인 생성

### 광고 목표 선택

| 목표 | 설명 | 추천 상황 |
|------|------|----------|
| **잠재고객(Lead)** | Meta가 전환 확률 높은 사용자에게 노출 | **픽셀 학습 후 권장** |
| 트래픽 | 랜딩 방문 자체에 최적화 | 초기 픽셀 데이터 부족 시 |

### 캠페인 유형

**Advantage+ 캠페인 추천** (2026 표준):

- 광고주 65%가 이미 사용
- 수동 타겟팅 대비 전환율 25% 향상
- URL + 예산만 넣으면 AI가 크리에이티브·타겟팅·입찰 자동 처리

### 타겟팅 설정

| 항목 | 설정 |
|------|------|
| 위치 | 대한민국 |
| 연령 | 25~55세 (자영업자 연령대) |
| 관심사 | 소상공인, 자영업, 베이커리, 카페, 제과, 창업 |
| 행동 | 중소기업 소유자, 페이스북 페이지 관리자 |
| 제외 | 기존 가입자 이메일 업로드해 제외 (Existing Customer Budget Cap 10~20%) |

### 예산

- 5만원 기준 **7일 집중 (일 7,000원)** 권장
- Meta 알고리즘 학습에 일 3~5만원 이상이 이상적이지만, 소액 테스트 목적이면 7일 집중이 효율적
- 일일 예산 방식이 총 예산 방식보다 유연

### 체크 포인트

- Advantage+ 쓰면 수동 타겟팅은 건드리지 않아도 됨 — 관심사만 초기 힌트로 입력
- 기존 고객 예산 캡 설정으로 신규 고객 확보에 집중

---

## STEP 9. 성과 모니터링

### 주요 지표

| 지표 | 의미 | 목표 |
|------|------|------|
| CPM | 1,000회 노출당 비용 | 낮을수록 좋음 |
| CPC | 클릭당 비용 | 300~500원 |
| CTR | 클릭률 | 1.5%+ |
| CVR | 전환율 (Lead 발생) | 5%+ |
| CPL | Lead 당 비용 | 5,000~10,000원 목표 |

### 실패 징후 감지

| 징후 | 조치 |
|------|------|
| CTR 1% 미만 | 소재 교체 |
| CVR 2% 미만 | 랜딩페이지 메시지 수정 |
| CPM 급등 | 타겟 경쟁 과열, 타겟 조정 |
| CPL 1만원 이상 | 소재 또는 타겟팅 조정 |
| CPL 5천원 이하 | 예산 증액 고려 |

### 체크 포인트

- 첫 3일은 학습 기간이라 지표가 불안정. 4일차부터 판단
- 소재 피로도 관리: 같은 소재 2주 넘기지 말 것

## 법적/정책 주의사항

- 한국 PIPA(개인정보보호법) 준수: 랜딩페이지에 **쿠키 동의 배너** 필수
- 개인정보 처리방침 링크 랜딩페이지에 포함 필수
- 픽셀 AI 자동 수집 기능이 켜져 있으면, 랜딩페이지에 **민감정보 노출 금지** (민감 페이지명, URL 경로 등)

## 참고
