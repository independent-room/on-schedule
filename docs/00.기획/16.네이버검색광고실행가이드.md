# 네이버 검색광고 실행 가이드

12.유저획득전략의 "네이버 검색광고 3만원" 실행을 위한 A to Z 가이드.

## 전체 흐름

```text
네이버 검색광고 계정 생성 (searchad.naver.com)
  → 사업자 정보 등록
    → 비즈채널 등록 (랜딩페이지 URL)
      → 광고 캠페인 생성 (파워링크)
        → 광고 그룹 생성 + 키워드 등록
          → 광고 소재 작성 (제목 + 설명 + URL)
            → 입찰가 설정 + 광고비 충전
              → 광고 게재
                → 성과 모니터링
```

---

## STEP 1. 네이버 검색광고 계정 생성

### 실행 절차

1. `searchad.naver.com` 접속
2. "회원가입" 클릭
3. 네이버 아이디로 로그인 (별도 계정 생성도 가능)
4. 광고주 유형 선택: **사업자 광고주**
5. 사업자등록번호 입력 → 자동 조회
6. 약관 동의 후 가입 완료

### 체크 포인트

- 개인사업자 등록증이 있으면 "사업자 광고주"로 가입해야 세금계산서 수령 가능
- 가입 직후 광고 집행 가능 (별도 심사 없음)

---

## STEP 2. 사업자 정보 등록

### 실행 절차

1. 검색광고 관리 > 광고시스템 > 설정 > 정보 관리
2. 사업자 정보 확인/수정
3. 세금계산서 수령 이메일 등록
4. 결제 정보 등록 (신용카드/계좌이체/무통장)

### 체크 포인트

- 광고비는 **선불 충전** 방식 (카드·계좌이체)
- 세금계산서는 매월 자동 발행

---

## STEP 3. 비즈채널 등록

비즈채널 = 광고가 연결될 **랜딩페이지 URL**. 광고를 만들기 전에 필수로 등록해야 함.

### 실행 절차

1. 광고시스템 > 도구 > 비즈채널 관리
2. "새 비즈채널 추가" 클릭
3. 채널 유형 선택:
   - 웹사이트 (랜딩페이지 주소)
   - 전화번호 (있으면 추가)
4. 랜딩페이지 URL 입력
5. 심사 요청 (1영업일 소요)

### 체크 포인트

- **심사 통과 안 되면 광고 집행 불가.** 랜딩페이지에 사업자 정보(상호, 대표자명, 사업자등록번호, 연락처, 주소) 표기 필수
- 개인정보 처리방침 링크 필수
- 서비스 소개가 명확하지 않으면 반려될 수 있음

---

## STEP 4. 광고 캠페인 생성 (파워링크)

파워링크 = 네이버 통합검색 상단에 노출되는 텍스트 광고. 가장 기본적인 검색광고 형식.

### 실행 절차

1. 광고시스템 > 광고 > 캠페인 만들기
2. 캠페인 유형: **파워링크** 선택
3. 캠페인 이름 설정 (예: "예약SaaS_검색광고_2026-04")
4. 하루 예산 설정 (일 1~3만원)
5. 캠페인 진행 기간 설정

### 체크 포인트

- 파워링크 외에도 쇼핑검색광고, 브랜드검색광고, 플레이스광고 등이 있지만, B2B SaaS에는 파워링크가 맞음
- 하루 예산 초과 시 자동으로 노출 중단 — 예산 통제 용이

---

## STEP 5. 광고 그룹 생성 + 키워드 등록

광고 그룹 = 유사한 키워드 + 광고 소재의 묶음 단위. 캠페인 > 광고 그룹 > 키워드 > 광고 소재 구조.

### 실행 절차

1. 캠페인 내 "광고 그룹 만들기" 클릭
2. 광고 그룹 이름 설정 (예: "예약관리_키워드")
3. 비즈채널 연결 (STEP 3에서 등록한 URL)
4. **기본 입찰가 설정** (70원부터 가능)
5. 키워드 등록

### 키워드 후보 (예약 SaaS 기준)

| 키워드 | 검색 의도 | 예상 CPC |
|--------|----------|----------|
| 예약 관리 프로그램 | 구매 의도 **강** | 300~800원 |
| 노쇼 방지 | 구매 의도 **중** | 500~1,500원 |
| 베이커리 예약 시스템 | 구매 의도 **강** | 200~500원 |
| 알림톡 예약 | 구매 의도 **중** | 300~700원 |
| 예약 관리 앱 | 구매 의도 **중** | 300~600원 |
| 매장 예약 솔루션 | 구매 의도 **강** | 500~1,200원 |

### 키워드 전략

- **롱테일 우선**: 3~4단어 조합 키워드가 단일 키워드보다 **CPC 저렴 + 전환율 높음**
- 예: "예약" (X, 경쟁 과열) → "베이커리 예약 관리 프로그램" (O)

### 체크 포인트

- 네이버 키워드 도구(searchad.naver.com > 도구 > 키워드 도구)로 검색량·경쟁도 사전 조사
- 너무 포괄적인 키워드는 피하기 ("예약" 단독 → 부적합)

---

## STEP 6. 광고 소재 작성

광고 소재 = 검색 결과에 실제 노출되는 **제목 + 설명 + URL**.

### 구성

| 항목 | 글자 수 제한 | 예시 |
|------|-------------|------|
| 제목 | **15자** | "예약 관리 + 노쇼 방지, 14,900원" |
| 설명 | **45자** | "DM 예약 대신 링크 하나로. 알림톡 무제한 포함. 1개월 무료 체험" |
| 표시 URL | 도메인 | yourservice.co.kr |
| 연결 URL | 랜딩페이지 실제 주소 | https://yourservice.co.kr/landing |

### 소재 작성 원칙

- 제목에 **키워드 포함**하면 품질지수 가산점 (광고 그룹의 키워드와 일치성)
- 혜택·차별점 명시 ("14,900원", "알림톡 무제한", "1개월 무료")
- 설명 끝에 **CTA** ("지금 신청하기", "1분 만에 시작")

### 체크 포인트

- 소재는 **광고 그룹당 최소 2개** 작성 → A/B 테스트
- 심사 1영업일 소요, 통과 후 노출 시작

---

## STEP 7. 입찰가 설정 + 광고비 충전

### 입찰가 전략

| 방식 | 설명 | 추천 상황 |
|------|------|----------|
| 수동 입찰 | 키워드별로 CPC 직접 지정 | 데이터 쌓인 후 |
| 자동 입찰 | 네이버가 자동 조정 | **초기 권장** |

### 초기 설정 (3만원 예산 기준)

- 기본 입찰가: **300~500원**
- 하루 예산: 일 3,000원 (10일치) 또는 일 1,500원 (20일치)
- 자동 입찰 켜고 2주 돌려서 데이터 수집

### 광고비 충전

1. 광고시스템 > 비즈머니 > 충전
2. 신용카드 또는 계좌이체
3. 최소 충전 금액: 10,000원
4. 충전 후 즉시 사용 가능

### 체크 포인트

- 입찰가가 너무 낮으면 노출이 안 됨 (경쟁 키워드는 최소 500원 이상)
- 일 예산 소진 시 자동 중단

---

## STEP 8. 네이버 광고 심사 통과 + 게재 시작

### 심사 절차

1. 비즈채널 심사 (STEP 3)
2. 광고 소재 심사 (STEP 6)
3. 둘 다 통과되면 자동 게재

### 심사 기간

- 통상 **1영업일** 내 완료
- 반려 시 사유 확인 후 수정 재제출

### 반려 주요 사유

| 사유 | 해결 |
|------|------|
| 랜딩페이지 사업자 정보 미표기 | 하단에 사업자등록증 정보 표기 |
| 과장 표현 ("최고", "1등") | 객관적 표현으로 수정 |
| 의료·법률 등 표현 | 일반 서비스 기준으로 재작성 |
| 타사 상표 사용 | 고유 브랜드명으로 교체 |

---

## STEP 9. 성과 모니터링

### 주요 지표

| 지표 | 의미 | 목표 |
|------|------|------|
| 노출수 | 검색 결과에 노출된 횟수 | 키워드·입찰가에 따라 변동 |
| 클릭수 | 광고 클릭 수 | - |
| CTR | 클릭률 (클릭÷노출) | **3%+** |
| CPC | 클릭당 비용 | 300~1,000원 |
| 전환수 | 사전 신청 완료 수 | - |
| CVR | 전환율 (전환÷클릭) | **5%+** |
| CPL | 전환 1건당 비용 | 5,000~15,000원 |

### 네이버 전환 추적 설정

네이버는 **프리미엄 로그 분석**이라는 무료 전환 추적 도구 제공.

1. 광고시스템 > 도구 > 프리미엄 로그 분석
2. 전환 스크립트 생성 → 랜딩페이지에 삽입
3. 사전 신청 완료 페이지에 이벤트 태그 추가
4. 전환 데이터 자동 수집

### 실패 징후 감지

| 징후 | 조치 |
|------|------|
| 노출 수 0건 | 입찰가 상향 또는 키워드 변경 |
| CTR 1% 미만 | 소재(제목/설명) 교체 |
| CVR 2% 미만 | 랜딩페이지 메시지 수정 |
| CPL 1만 5천원 이상 | 키워드/소재/랜딩 전체 점검 |

## 전체 체크리스트

| # | 항목 | 필수/선택 | 완료 |
|---|------|----------|------|
| 1 | 검색광고 계정 생성 | 필수 | [ ] |
| 2 | 사업자 정보 + 결제 수단 | 필수 | [ ] |
| 3 | 비즈채널 등록 + 심사 통과 | 필수 | [ ] |
| 4 | 캠페인 생성 (파워링크) | 필수 | [ ] |
| 5 | 광고 그룹 + 키워드 5~10개 | 필수 | [ ] |
| 6 | 광고 소재 2개 이상 + 심사 통과 | 필수 | [ ] |
| 7 | 입찰가 설정 + 비즈머니 충전 | 필수 | [ ] |
| 8 | 프리미엄 로그 분석 전환 추적 | 권장 | [ ] |

**블로커:** 3번(비즈채널 심사)이 가장 먼저 해결해야 할 관문. 랜딩페이지가 없거나 사업자 정보 미표기 시 광고 집행 불가.

## 인스타 광고와의 차이 요약

| 항목 | 인스타 | 네이버 검색 |
|------|--------|------------|
| 유입 타입 | 문제 인지 (푸시형) | 니즈 명확 (풀형) |
| 타겟팅 | 관심사 기반 | 키워드 기반 |
| CPC | 300~500원 | 300~1,000원 |
| CVR | 낮음 (2~5%) | **높음 (5~15%)** |
| 볼륨 | 큼 | 적음 (검색량 제한) |
| 적합 용도 | 볼륨 확보 | 전환 확보 |

**결론:** 검색광고는 "이미 해결책을 찾는 사장님"을 잡는 채널이라 **전환율은 높지만 볼륨이 적음.** 3만원 예산으로 노출이 충분히 안 나올 수 있으니, 검색량이 적은 키워드라면 예산을 인스타로 이동하는 것도 고려.

## 법적/정책 주의사항

- 랜딩페이지에 사업자 정보(상호, 대표자명, 사업자등록번호, 주소, 연락처) 표기 필수
- 개인정보 처리방침 링크 필수
- 과장 광고 금지: "최고", "1등", "유일" 등 표현 피하기
- 타사 상표·브랜드명 광고 소재 사용 금지
