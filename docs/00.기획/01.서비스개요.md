# 서비스 개요

## 한 줄 정의

소상공인을 위한 예약 + CS 챗봇 + CRM 통합 도구. **사장님이 자기 가게 예약 폼을 단계별로 직접 만드는 SaaS.** 채널톡 + 예약 시스템 + CRM을 하나로, 소상공인 가격에 제공한다.

## 포지셔닝

**"채널톡의 예약 버전" + "5분 셋팅"** — 사장님이 자기 채널(인스타, 카카오, 자사몰)에 붙이는 범용 예약·CS 도구. 메뉴·시간·결제·알림 단계별로 따라가면 5분 안에 완성.

- 마켓플레이스(캐치테이블형)가 아님. 고객이 서비스에서 가게를 "발견"하는 구조가 아님
- 사장님이 가져다 쓰는 도구. 채널톡이 채팅 위젯을 어디든 붙이듯, 예약 링크를 어디든 붙이는 구조
- 시스템은 업종 불문 범용, 마케팅/온보딩은 베이커리/디저트 니치부터 진입
- **예약 폼은 사장님이 직접 단계별 셋업 위저드로 구성** (시간 처리 5패턴 중 선택)
- 예약 플로우는 업종 불문 동일하게 가져감

## 레퍼런스

**지금예약 ((주)루머) — 창업자 실무 경험**

- 예약 관리 SaaS (베이커리, 타투, 반영구 등 복수 업종)
- 유료 전환 사용자 존재 확인
- 실패 원인 분석 완료 → 이번 서비스에 반영
- 링크인바이오 예약 페이지 제공 경험 있음 (팅커뷰링크와 유사)

## 기존 실패에서 배운 것

| 지금예약 실패 원인 | 이번에 다르게 할 것 |
|---|---|
| 7명 인건비 감당 불가 | 1인 운영 + AI 생산성 |
| 기능 중구난방 (부가 유틸 위주) | 예약+CS+CRM 핵심에만 집중 |
| 타겟 분산 (베이커리, 타투, 반영구 등) | 시스템은 범용, 마케팅은 베이커리 니치 특화 |
| MVP 품질 저하 | 높은 초기 품질 (기술력 성장 + AI) |
| SNS 광고 1000만원 효과 미미 | 커뮤니티 기반 + 랜딩페이지 검증 |

## 현재 사장님이 쓰는 도구 스택과 대체 범위

| 현재 | 비용 | 본인 서비스로 대체 |
|------|------|--------------------|
| 채널톡 (CS) | 72,000원~/월 | → RAG 챗봇으로 대체 |
| 팅커뷰 (예약) + 링크 | 19,800원/월 | → 예약 관리 + 예약 링크로 대체 |
| 알림톡 (별도 충전) | ~2,700원/월 | → 알림톡 무제한 포함 |
| 엑셀 (CRM) | - | → 자동 고객관리로 대체 |
| **합계** | **~94,500원+** | **→ 19,900원** |
