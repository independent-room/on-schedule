# 기술 타당성 검토

## 카카오 알림톡

| 항목 | 내용 |
|---|---|
| 알림톡 건당 단가 | ~9원 (중계사 기준) |
| 일일 초기 한도 | 1,000건/일 (상향 요청 가능) |
| 마케팅 발송 가능 시간 | 08:00 ~ 20:50 |
| 차단 사전 조회 | 불가 (발송 후 실패 코드로 확인) |
| 운영 정책 위반 제재 | 최소 30일 ~ 영구 사용 제한 |
| 2026년 변경 | 친구톡 → 브랜드메시지로 통합 |

### 채널 연동 전/후

| 단계 | 주문 알림 | 마케팅 메시지 |
|---|---|---|
| 비즈니스 미등록 | 플랫폼 채널("[서비스명] 알림")로 발송 | 사용 불가 |
| 비즈니스 등록 완료 | 매장 자체 채널로 전환 | 사용 가능 |

## RAG 챗봇 (v3)

| 항목 | 내용 |
|---|---|
| 구조 | 사장님 문서 업로드 → 임베딩 → 벡터DB → 고객 질문 시 유사 문서 검색 → LLM 답변 생성 |
| 필요 스택 | 임베딩 API (OpenAI 등) + 벡터DB (Supabase pgvector 등) + LLM API |
| 건당 비용 | ~50~200원 (모델/토큰에 따라) |
| 개발 난이도 | 중간 — RAG 파이프라인은 잘 정립된 패턴 |
| 리스크 | LLM 품질 관리 (잘못된 답변 → 사장님 신뢰 하락) |

## 인스타그램 연동 (v4)

| 항목 | 내용 |
|---|---|
| API | Instagram Graph API + Messenger API for Instagram |
| 허들 | **Meta 앱 검수** — 까다롭고 수주 소요 |
| 제약 | 24시간 메시징 윈도우, 시간당 200 DM, 콜드 아웃리치 금지 |
| 요구사항 | 사장님 비즈니스 계정 + 페이스북 페이지 연결 |
| 용도 | 예약 유입 입구 (댓글→DM→예약링크). 운영 채널로는 부적합 |

## PG 결제 (v4)

| 항목 | 내용 |
|---|---|
| PG사 | 토스페이먼츠 등 |
| 영세 가맹점 수수료 | 0.4% (네이버 예약 3.74% 대비 1/9) |
| 가상계좌 | 건당 400원 |
| PG 가입비/관리비 | 연 33만원 (월 약 2.7만원) |
| MVP 제외 이유 | 개발 스코프 증가 + 환불/정산/법적 이슈 |

## 법적 이슈

- 개인정보: 고객 전화번호 수집/보관 → 개인정보처리방침 필수
- 알림톡: 카카오 운영 정책 준수
- PG 결제 (v4): 영세 가맹점 등록 요건 확인 필요
- 인스타 연동 (v4): Meta 플랫폼 정책 준수
