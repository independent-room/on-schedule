# 고객 발견 / 문제 검증

## 현재 검증 상태

| 가설 | 상태 | 근거 |
|------|------|------|
| 베이커리 사장님들이 예약/노쇼 문제를 겪고 있다 | **부분 검증** | 지금예약 경험 + 노쇼 통계 |
| 네이버 예약이 니즈를 충분히 해결하지 못한다 | **부분 검증** | 알려진 한계점 (직접 인터뷰 미실시) |
| 월 14,900원 지불 의향이 있다 | **부분 검증** | 지금예약에서 유료 사용자 존재 |
| 1인 운영이 가능하다 | **미검증** | 개발 과정에서 검증 필요 |

### 주의: "있으면 좋겠다"는 검증이 아니다

주변 자영업자들에게 "이런 서비스 있으면 어때?"라고 물으면 다 좋다고 답한다. 이건 관계 때문이지 지불 의향이 아니다. 진짜 검증은 **"지금 이 문제를 어떻게 해결하고 있어요?"**라고 물었을 때 나온다 (The Mom Test).

## 검증 전략: Waitlist-to-Interview 퍼널

인터뷰 대상이 주변에 없으므로, **광고로 관심 있는 사장님이 먼저 손을 들게 만들고, 그 사장님에게 인터뷰를 요청**하는 방식.

```text
랜딩페이지 제작
    → 인스타/네이버 광고 (10만원)
        → 사전 신청자 발생
            → 신청자에게 "10분만 통화 가능하세요?" 요청
                → 인터뷰 성사 (정성 검증)
```

### 왜 이 방식인가

| 기존 계획 (콜드 접근) | 변경된 계획 (Waitlist-to-Interview) |
|---------------------|----------------------------------|
| 인스타 DM 20~30곳 발송 | 광고로 관심 있는 사장님이 먼저 신청 |
| 응답률 5~10% | 신청자 인터뷰 응답률 **30~50%** |
| 시간 많이 소모, 거절 스트레스 | 관심 표현한 사람만 접촉, 효율적 |
| 정량 검증 별도 필요 | **정량(전환율) + 정성(인터뷰) 동시 해결** |

### 레퍼런스

| 서비스 | 전략 |
|--------|------|
| Superhuman | 웨이트리스트 신청자 전원에게 30분 온보딩 콜 → 제품 피벗에 활용 |
| Notion | 초기 대기 리스트 신청자 인터뷰 → 기능 설계에 반영 |
| Clubhouse | 1,000만명 대기 리스트, 대기 중 피드백 수집 |

## 실행 계획

### 1단계: 랜딩페이지 제작 (1~2일)

**구성:**
- 핵심 메시지: 인터뷰/광고 테스트에서 가장 공감 받는 페인포인트 기반
- 가치 제안: "노쇼 관리 + 알림톡 무제한 + 예약 링크, 14,900원"
- CTA: "사전 신청" 버튼 (이메일 또는 전화번호 수집)
- 제작 방법: Nano Banana Pro(디자인 레퍼런스) + Claude(코드)

### 2단계: 광고 테스트 (2주, 10만원)

| 채널 | 예산 | 목적 |
|------|------|------|
| 인스타 광고 | 5만원 | 유입량 테스트 — 어떤 메시지에 클릭하는지 |
| 네이버 검색광고 | 3만원 | 전환 테스트 — "예약 관리", "노쇼 방지" 키워드 |
| 네이버 블로그 | 무료 | 3~5개 글 발행 (검색 유입 누적) |
| 네이버 카페 | 무료 | "아프니까 사장이다" 리서치형 게시글 |
| 예비 | 2만원 | 소재 변경 후 재테스트용 |

### 3단계: 신청자 인터뷰 (신청 발생 즉시)

**방법:**
- 사전 신청 완료 페이지에서 "서비스 준비 중입니다. 10분만 통화 가능하시면 더 좋은 서비스를 만들겠습니다" 안내
- 또는 신청 후 24시간 이내 이메일/문자로 인터뷰 요청

**핵심 질문 (The Mom Test 방식):**

1. "지금 예약/주문을 어떤 방식으로 받고 계세요?" (현재 행동)
2. "그 방식에서 가장 불편한 점이 있으시다면요?" (페인포인트)
3. "노쇼가 발생하면 어떻게 대처하세요?" (대안 행동)
4. "예약 관리에 도구를 써보신 적 있으세요? 있다면 왜 그만두셨어요?" (기존 대안 평가)
5. "예약 확정/리마인드 알림을 직접 보내세요?" (수동 알림 부담 확인)
6. **"메뉴, 시간, 알림 같은 걸 단계별로 셋팅하는 도구 있으면 쓰시겠어요?"** (셋업 위저드 가설 검증)
7. **"기존에 도구 셋팅하다가 막혀서 포기하신 적 있으세요?"** (빈 화면 공포증 검증)

**하지 말 것:**
- "이런 기능 있으면 쓰시겠어요?" (유도 질문)
- "월 14,900원이면 괜찮으시겠죠?" (가격 유도)
- "5분 만에 셋팅됩니다, 좋죠?" (단정형 유도)

### 4단계: 판단

| 결과 | 다음 행동 |
|------|----------|
| 전환율 5%+ AND 인터뷰 3명+ 구체적 페인포인트 확인 | **개발 착수** |
| 전환율 OK but 인터뷰에서 페인포인트 약함 | 타겟 또는 가치 제안 피벗 |
| 전환율 낮음 | 메시지 피벗 후 재테스트 (2개월차 예산 활용) |
| 전환율 + 인터뷰 둘 다 실패 | 프로젝트 방향 재검토 또는 중단 |

## 성공 기준

| 지표 | 기준 | 근거 |
|------|------|------|
| 랜딩페이지 방문자 | 200명 이상 | 10만원 광고 예산 기준 달성 가능 |
| 사전 신청 전환율 | **5% 이상** (10명+) | 업계 평균 웨이트리스트 전환율 20~40%의 하한 |
| 인터뷰 성사 | **3명 이상** | 신청자 응답률 30~50% 기준, 10명 중 3~5명 |
| 인터뷰 내용 | 3명 중 2명 이상 구체적 페인포인트 표현 | "있으면 좋겠다"가 아닌 "지금 이것 때문에 N시간/N만원 낭비" |

## 주의사항

### 웨이트리스트 신청 ≠ 검증

이메일 남기는 건 공짜다. 진짜 검증은:
- 신청 후 인터뷰에서 **구체적인 페인포인트를 말하는지**
- **"출시되면 쓰겠다"가 아니라 "지금 이 문제 때문에 돈/시간을 잃고 있다"**고 말하는지

웨이트리스트 숫자에 취하지 말 것. 인터뷰 내용이 본질이다.

## 실행 타임라인

| 시점 | 행동 |
|------|------|
| **지금 (재직 중)** | 근로계약서 경업 조항 확인 |
| **이직 전 1주차** | 랜딩페이지 제작 |
| **이직 전 2~3주차** | 인스타/네이버 광고 테스트 (10만원) |
| **신청 발생 시** | 신청자 인터뷰 (즉시) |
| **이직 후 1주차** | 결과 판단 → 개발 착수 or 피벗 |
