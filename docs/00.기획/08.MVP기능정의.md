# MVP 기능 정의

## 단계별 기능 로드맵

### MVP (2~3개월) — 14,900원

핵심 가설 검증에 필요한 최소 기능. "사장님이 자기 가게 예약 폼을 단계별로 만드는 도구."

| # | 기능 | 설명 |
|---|---|---|
| 1 | **단계별 셋업 위저드** | 메뉴 → 시간 → 결제 → 알림 → 완료 5단계. 각 단계 안에서 옵션 선택. 5분 셋팅 |
| 2 | 예약 접수/관리 | 예약 페이지 링크 → 날짜/메뉴/픽업시간 선택 → 사장님 확정/거절 |
| 3 | 예약 링크 (링크인바이오) | 인스타/카카오/블로그 어디든 붙일 수 있는 전용 예약 링크 + QR코드 |
| 4 | 메뉴별 수량 제한 | 일일 최대 수량 설정 → 초과 예약 자동 마감 |
| 5 | 노쇼 고객 이력 관리 | 노쇼 횟수 누적, 경고 알림, 재예약 제한 설정 |
| 6 | 알림톡 자동 발송 (무제한) | 예약 확정 / 전날 리마인드 / 픽업 준비완료 |
| 7 | 사장님 대시보드 | 예약 캘린더 뷰, 오늘 예약 목록 |

> 선결제/보증금(PG 연동)은 MVP에서 제외. 개발 스코프가 커지고 법적 이슈도 있어 v2 이후 검토.

### 단계별 셋업 위저드 — 핵심 설계 원칙

배민 사장님 입점 셋업 모범 사례 차용. 빈 화면 공포증 제거 + 5분 내 완료 목표.

| 단계 | 내용 | 사장님 결정 |
|------|------|----------|
| 1. **메뉴** | 메뉴명·설명·가격·수량 한도·이미지(선택) | 옵션 자유도 높음 |
| 2. **시간** | 5가지 패턴 중 선택: ①시간 슬롯 / ②일 단위 수량 / ③시간+인원 / ④픽업 시간대 / ⑤날짜만 | 패턴 선택 → 세부 입력 |
| 3. **결제** | 결제 안 받음 / 매장에서 직접 / (v2 이후) 정액 예약금 | 단순 선택 |
| 4. **알림톡** | 예약 확정·리마인드·픽업 알림 메시지 템플릿 미리 채워짐 → 가게명만 수정 | 템플릿 기반 |
| 5. **완료** | 예약 링크 발급 + QR코드 + 인스타·카톡 공유 가이드 | 결과 확인 |

**설계 원칙:**
- **각 단계에 기본값 미리 채워둠** (배민 OCR + 자동 입력 패턴)
- **단계 수 5개** (3~7 권장 범위 안)
- **진행률 표시** (완료율 +20~30% 효과)
- **셋업 후 첫 액션 워크스루** (위저드만으론 활성화 부족, 첫 예약 받기까지 가이드)

### 시간 처리 5패턴 (단계 2의 옵션 풀)

사장님이 자기 가게 특성에 맞춰 선택. 패턴별 사례:

| 패턴 | 예시 업종 |
|------|---------|
| ① 분 단위 시간 슬롯 | 미용실, 컨설팅, 마사지, PT |
| ② 일 단위 수량 한도 | 베이커리, 도시락, 떡집, 꽃집 |
| ③ 시간 + 인원 한도 | 베이킹 클래스, 요가, 공방 |
| ④ 픽업 시간대 + 수량 | 매장 픽업, 사전 주문, 케이터링 |
| ⑤ 날짜만 + 수량 | 주문제작, 일 배달 |

→ 한 SaaS로 5개 패턴 모두 커버. 도메인 고정 SaaS와의 차별점.

## 인스타그램 연동 정책 (2026년 기준)

### 가능한 것

- 고객이 댓글/DM/스토리답장 → 자동 응답 (24시간 윈도우 내)
- "예약" 댓글 → 예약 링크 자동 DM 발송
- DM 문의 → RAG 챗봇 자동 응답
- 시간당 자동 DM 200건 제한

### 불가능한 것

- 24시간 지난 후 메시지 발송 (리마인드 불가 → 카카오 알림톡으로 처리)
- 먼저 DM 보내기 (콜드 아웃리치 금지)
- 대량 DM/마케팅 메시지

### 필수 요구사항

- 사장님 인스타 비즈니스/크리에이터 계정
- 페이스북 페이지 연결
- Meta 앱 검수 통과 (수주 소요)

### 결론

인스타 연동은 "입구"로 유용하지만 "운영 채널"로는 못 씀. 예약 유입은 인스타, 이후 알림/CS는 카카오 알림톡이 메인.
