# MVP 기능 정의

## MUST — 이게 없으면 서비스가 아님

핵심 가설 검증에 필요한 최소 기능. 노쇼 관리 + 알림톡 + 낮은 수수료.

| # | 기능 | 설명 | 소스 |
|---|---|---|---|
| 1 | 예약 접수/관리 | 예약 페이지 링크 → 날짜/메뉴/픽업시간 선택 → 사장님 확정/거절 | 예약-주문관리 |
| 2 | 메뉴별 수량 제한 | 일일 최대 수량 설정 → 초과 예약 자동 차단 | 예약-주문관리 |
| 3 | 주문 상태 관리 | 접수 → 확정 → 제작 중 → 픽업 준비완료 | 예약-주문관리 |
| 4 | 선결제 / 예약 보증금 | PG 결제, 전액 or 계약금만 선택 가능 | 노쇼관리, 결제-정산 |
| 5 | 노쇼 고객 이력 관리 | 노쇼 횟수 누적, 경고 알림, 재예약 제한 설정 | 노쇼관리 |
| 6 | 알림톡 자동 발송 | 예약 확정 / 전날 리마인드 / 픽업 준비완료 | 알림-커뮤니케이션 |
| 7 | 사장님 대시보드 | 예약 캘린더 뷰, 오늘 예약 목록 | 예약-주문관리 |
