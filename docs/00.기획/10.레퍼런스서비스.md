## 단계별 셋업 위저드 모범 사례 (MVP 셋업 화면 참고)

본인 서비스 MVP의 핵심 기능 = "메뉴→시간→결제→알림" 단계별 셋업. 아래 사례를 차용.

### 배달의민족 사장님 입점 (가장 직접적 참고)

- **출처**: 우아한형제들 기술블로그
- **개선 결과**:
  - 사업자정보 단계 6개 → 4개로 축소
  - 평균 소요 시간 -5.9시간
  - **10분 내 완료율 58.5% → 82.7% (+24.2%p)**
- **핵심 패턴**:
  - OCR로 사업자등록증 자동 입력
  - 대화형 UI (한 번에 한 작업)
  - 단계 수 의도적 감소
- **본인 서비스 적용**:
  - 메뉴/시간/결제/알림 5단계 (3~7 권장 범위 안)
  - 각 단계 기본값 미리 채움
  - 진행률 표시 + 체크리스트

### Stripe Connect Onboarding (글로벌 모범)

- 단일 hosted URL에서 단계 자동 분기
- 시스템이 무엇이 필요한지 알고 다음 단계만 안내
- **본인 서비스 적용**: 시간 처리 패턴 선택 후 그 패턴에 맞는 입력만 노출

### Shopify Tutorial (2026)

- 6단계 흐름 (계정 → AI 셋업 → 환경설정 → 테마 → 상품 → 공개)
- AI가 사전 질문으로 starter store 자동 생성
- **본인 서비스 적용**: 향후 v3에서 AI 셋업 보조 검토 (메모리 1인 구현 가능성 필터 고려)

### Square Appointments

- 5단계 권장 셋업 (강제 위저드 X, 가이드형)
- **본인 서비스 적용**: 강제 위저드 + 이후 자유 수정 가능

### 컨피규레이터 vs 풀 빌더

| 본인 서비스 = 컨피규레이터 (단계별 + 옵션 풍부) | 풀 빌더 (Booknetic, Wix Bookings) |
|------|------|
| 시작점: 고정된 단계 흐름 | 빈 캔버스 |
| 자유도: 각 단계 안에서만 높음 | 무한 |
| 학습 곡선: 완만 | 가파름 |
| 1인 개발 부담: 중간 | 매우 큼 |

### SaaS 온보딩 BP (검증된 수치)

- 단계 수: 3~7 권장 (20단계 넘으면 완료율 -30~50%)
- Time-to-Value: 5분 이내
- 진행률/체크리스트: 완료율 +20~30%
- 인터랙티브 위저드: 활성화율 +50%
- **위저드만으론 부족** → 셋업 후 첫 액션 워크스루 필요
