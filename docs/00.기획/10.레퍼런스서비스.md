# 레퍼런스 서비스 조사

기능 백로그 작성 시 참고한 국내외 서비스 조사 결과.

---

## 국내

### 콜라보살롱

- **분류**: 뷰티 / 살롱 예약 관리
- **웹사이트**: colavo.kr
- **주목한 기능**
  - 플랫폼<->매장 채널 전환: 채널 미연동 시 "콜라보살롱 알림" 채널 발송, 연동 후 매장 자체 채널로 전환
  - 매니저톡(PLUS): 방문 예정 알림, 회원권 잔여 안내 자동 발송. 1건 = 1포인트(16~20원)
  - 단체문자(PLUS): 세그먼트 대상 마케팅 메시지 발송
- **비고**: 뷰티 살롱 특화. 포인트 별도 충전 방식 -- 우리가 구독 포함 방식으로 차별화할 지점.

### 캐치테이블

- **분류**: 레스토랑 예약 관리
- **웹사이트**: catchtable.co.kr
- **주목한 기능**
  - 웨이팅: 현장 대기 고객에게 입장 번호 부여, 순서 되면 알림
  - 예약금 시스템: 노쇼 방지용 보증금 설정
  - 알림톡 자동 발송: 예약 확정, 중간 안내, 최종 안내 각각 발송 시점 설정 가능
  - 전화 팝업: 전화 수신 시 고객 방문 이력 자동 표시
  - 네이버 예약 연동: 캐치테이블 하나로 통합 관리
  - 삼진아웃 제도: 노쇼 3회 고객 예약 자동 차단
- **비고**: 레스토랑 특화라 베이커리와 직접 겹치지 않음. 웨이팅/노쇼 처리 구조 참고.

### 네이버 예약

- **분류**: 범용 예약 플랫폼
- **주목한 이유**: 비교 대상 (우리가 이겨야 할 서비스)
- **한계점**
  - 결제 수수료 3.74% (영세 가맹점 PG 0.4% 대비 9배)
  - 자동 확정 방식 (사장님이 거절 불가)
  - 픽업 시간 30분/1시간 단위 고정
  - 중복 예약 발생 가능 (일일 생산량 제한 없음)
  - CRM 없음 (단골 관리, 노쇼 이력 추적 불가)

## 글로벌 뷰티 / 살롱

### Fresha

- **분류**: 글로벌 뷰티 / 살롱 예약 SaaS
- **웹사이트**: fresha.com
- **주목한 기능**
  - 기프트카드: 온라인으로 구매해 지인에게 선물. 수령자가 예약 시 코드로 결제
  - 로열티 포인트: 구매 금액 기반 포인트 적립 -> 할인/무료 증정으로 전환
  - 멤버십: 월정액 N회 이용 구독형 패키지
  - 재고 관리: 제품별 재고 추적, 판매 시 자동 차감
- **수익 모델**: 무료 + 신규 고객 첫 예약 시 20% 수수료 (마켓플레이스 입점 형태)
- **비고**: 마켓플레이스 모델은 우리 방향과 다름. 기프트카드/로열티/멤버십 기능 참고.

### Vagaro

- **분류**: 미국 뷰티 / 살롱 관리 소프트웨어
- **웹사이트**: vagaro.com
- **주목한 기능**
  - 재고 관리: 제품 추적, 저재고 알림, 판매 시 자동 차감
  - 직원 급여 계산: 서비스/제품별 커미션 요율 설정
  - 시설/장비 자원 관리: 예약 시 특정 장비나 공간 자동 배정 및 중복 예약 방지
- **가격**: 1인 $30/월, 전문가 $50/월, 비즈니스 $80/월

### GlossGenius

- **분류**: 미국 뷰티 전문가용 예약 소프트웨어
- **웹사이트**: glossgenius.com
- **주목한 기능**
  - 리부킹 자동 리마인더: 픽업/시술 완료 후 N일 뒤 "다음 예약 안 잡으셨어요?" 자동 문자. 재방문율 75%+ 달성 사례
  - 리뷰 자동 요청: 방문 후 자동으로 구글 리뷰 요청. 구글 5점 리뷰 200개 달성 사례
  - 무제한 자동 메시지: 확인/리마인드/감사/팔로업 텍스트+이메일 추가 과금 없음
- **비고**: 1인 뷰티 전문가 특화. "리부킹 자동화"가 핵심 차별점.

### Boulevard

- **분류**: 미국 프리미엄 살롱/스파 소프트웨어
- **웹사이트**: joinblvd.com
- **주목한 기능**
  - Precision Scheduling: 예약 사이 빈 시간을 최소화하는 AI 일정 최적화. 캘린더 효율 극대화
  - 멤버십 + 로열티: 구독형 패키지와 포인트 프로그램 내장
- **비고**: 프리미엄 포지셔닝. AI 스케줄 최적화를 생산 배치 최적화에 응용 가능.

### Booksy

- **분류**: 글로벌 뷰티 예약 마켓플레이스 + 관리 도구
- **웹사이트**: biz.booksy.com
- **주목한 기능**
  - 인스타그램 직접 예약: 인스타 프로필에서 외부 링크 이동 없이 바로 예약 가능
  - 라스트 미닛 오프닝 알림: 갑자기 빈 슬롯 발생 시 주변/관심 고객에게 즉시 알림 발송
  - Boost(마켓플레이스 노출 강화): 유료로 플랫폼 내 검색 상단 노출
- **비고**: 마켓플레이스 성격 강함. 인스타 직접 예약 UX 참고.

### Mangomint

- **분류**: 미국 살롱/스파 관리 소프트웨어
- **웹사이트**: mangomint.com
- **주목한 기능**
  - 양방향 문자 채팅(Connect): 전화/문자/웹챗을 앱 안에서 통합. 고객과 채팅처럼 주고받기
  - 스마트 대기 리스트: 취소 발생 시 대기 중인 고객에게 자동 매칭 및 알림
  - 자원 관리: 예약 시 장비/공간 자동 배정, 중복 예약 방지
  - 그룹 예약: 여러 명이 함께 하나의 슬롯 공유, 개별/일괄 정산 지원

### Phorest

- **분류**: 영국/아일랜드 살롱 관리 소프트웨어
- **웹사이트**: phorest.com
- **주목한 기능**
  - 리뷰 자동 요청: 방문 후 이메일/SMS로 자동 리뷰 요청 발송. 긍정 리뷰만 구글/페이스북으로 유도, 부정 피드백은 사장님에게만 전달
  - 비포/애프터 사진: 시술 전후 사진을 고객 프로필에 저장. 재방문 시 이전 기록 즉시 확인

## 글로벌 범용 예약

### SimplyBook.me

- **분류**: 글로벌 범용 온라인 예약 시스템
- **웹사이트**: simplybook.me
- **주목한 기능**
  - 인테이크 폼: 예약 시 커스텀 정보 수집. 텍스트/드롭다운/파일 업로드 등 다양한 필드
  - 대기 리스트: 마감된 슬롯 대기 등록 -> 취소 시 자동 연락
  - 예약 보증금(Deposit): 예약 시 부분 결제로 노쇼 방지
  - 취소 수수료 정책: 취소 시점별 다른 환불 정책 설정
  - 멤버십/구독: 횟수권 패키지 판매
  - 쿠폰/기프트카드/팁: 다양한 결제 부가 기능

### Acuity Scheduling

- **분류**: 글로벌 범용 예약 자동화 도구
- **웹사이트**: acuityscheduling.com
- **주목한 기능**
  - 구글/아웃룩/애플 캘린더 연동: 개인 일정과 예약 일정 통합 관리
  - 커스텀 인테이크 폼: 예약 유형별 다른 폼 설정 가능
  - 자동 이메일/SMS 리마인더: 확인/리마인드 자동 발송

### SevenRooms

- **분류**: 글로벌 레스토랑 CRM + 예약 소프트웨어
- **웹사이트**: sevenrooms.com
- **주목한 기능**
  - 예약 업셀링: 예약 흐름 중 부가 옵션 추가 판매 (창가 자리, 꽃다발, 초콜릿 등)
  - VIP 우선 오픈 알림: 인기 날짜 오픈 시 고가치 고객에게 먼저 알림
  - 양방향 SMS: 예약 전후 고객과 직접 문자 소통
  - AI 자동 착석: 테이블 배치 최적화 알고리즘

## 베이커리 특화 (해외)

### CakeBoss

- **분류**: 미국 베이커리/케이크 주문 관리 소프트웨어
- **웹사이트**: cakeboss.com
- **주목한 기능**
  - 케이크 가격 자동 계산: 사이즈/맛/필링/데코 선택 -> 가격 자동 계산
  - 계약금 + 잔금 분할 결제: 납부 기한 설정 및 자동 알림
  - 생일/기념일 마케팅: 고객 생일/기념일 저장 -> 자동 메시지 발송
  - 완성품 사진 + 인보이스: 주문별 사진 첨부 및 로고 포함 PDF 인보이스 발송
- **가격**: 일회성 $149

### BakeSmart

- **분류**: 미국 베이커리 주문/생산 관리 소프트웨어
- **웹사이트**: bakesmart.com
- **주목한 기능**
  - 생산 스케줄 자동화: 예약 데이터 기반으로 당일/다음날 생산 목록 자동 생성
  - 커스텀 케이크 가격 계산: 사이즈, 맛, 필링, 데코 옵션별 가격 자동 계산
  - POS 연동: 워크인 판매와 예약 주문 통합 관리
- **가격**: $99/월~

### Craftybase

- **분류**: 글로벌 홈 베이커리 / 수공예 재고 관리
- **웹사이트**: craftybase.com
- **주목한 기능**
  - 레시피 원가 계산: 재료별 단가 입력 -> 레시피별 원가 자동 계산
  - 배치 추적: 생산 배치별 재료 사용량 기록, 품질 이슈 역추적
  - 저재고 알림: 재료 재고 기준 이하 시 자동 알림
  - 실시간 재고 추적: 판매/생산 시 자동 차감
- **가격**: $24/월~

### Zymo

- **분류**: 글로벌 베이커리 ERP
- **웹사이트**: zymo.org
- **주목한 기능**
  - 영양정보 자동 생성: 레시피 입력 -> 영양성분표 자동 계산
  - 도매 주문 관리: 납품처별 상시 주문 관리
  - 생산 스케줄: 예약/주문 기반 생산 일정 자동화

### HoneyBook

- **분류**: 미국 크리에이티브 소규모 사업자용 CRM
- **웹사이트**: honeybook.com
- **주목한 기능**
  - 고객 설문(Questionnaire): 커스텀 주문 전 고객 요구사항 수집 폼
  - 계약서 + 인보이스: 전자 계약서 발송 및 서명, 로고 포함 인보이스
  - 분할 결제: 계약금/잔금 납부 일정 자동화
  - 리드 캡처 폼: 문의 -> 주문 전환 플로우 자동화
- **비고**: 베이커리를 포함한 크리에이티브 소규모 사업자 다수 사용.
