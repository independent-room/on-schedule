# 알림톡 & 마케팅 메시지 전략

## 핵심 방향

> 사장님은 추가 비용 걱정 없이 마음껏 쓰고, 우리는 마진을 확보한다.
> 건당 충전 모델(콜라보살롱 방식)은 사장님이 아끼려 해서 활용도가 떨어지므로 채택하지 않는다.

---

## 메시지 종류 구분

### 알림톡 (정보성 -- 주문 프로세스)

- 예약 확정 / 전날 리마인드 / 픽업 준비완료
- 채널 친구 여부와 무관, 전화번호 기반 발송
- 24시간 발송 가능
- 발송 실패 시 SMS 대체발송 가능 (사장님 on/off 설정)

### 마케팅 메시지 (광고성 -- 브랜드메시지/친구톡)

- 신메뉴 안내 / 시즌 이벤트 / 재방문 유도
- 채널 친구 + 마케팅 수신 동의 고객에게만 발송 가능
- 발송 시간: 08:00 ~ 20:50만 가능 (카카오 정책)
- 2026년 1월부터 친구톡 -> 브랜드메시지로 통합

## 스마트 타겟팅 (세그먼트)

### 기본 원칙

전체 발송이 아닌 타겟 발송으로 비용을 줄이고 효과를 높인다.
세그먼트는 **우리가 미리 정의해서 제공**한다. 사장님이 직접 조건을 설정하지 않아도 된다.

### 제공 세그먼트 (자동 생성)

| 세그먼트 이름 | 내부 조건 | 예시 인원 |
|---|---|---|
| 단골 고객 | 최근 3개월 내 3회 이상 주문 | 32명 |
| 오래 안 오신 고객 | 마지막 주문 3개월 이상 경과 | 28명 |
| 케이크 주문 고객 | 케이크 카테고리 주문 이력 | 45명 |
| 신규 고객 | 첫 주문 후 14일 이내 | 8명 |
| 전체 고객 | 전체 | 156명 |

### UX 방향

```text
누구한테 보낼까요?

단골 고객           32명
오래 안 오신 고객    28명
케이크 주문 고객     45명
신규 고객            8명
전체 고객          156명
```

"세그먼트"라는 단어를 노출하지 않고, "누구한테 보낼까요?" 형태로 제공한다.

### 타겟팅 효과

| 구분 | 전체 발송 | 스마트 타겟팅 |
|---|---|---|
| 대상 인원 (월 4회 캠페인) | 500명 x 4회 = 2,000건 | ~100명 x 4회 = 400건 |
| 마케팅 비용 (원가) | ~36,000원 | ~7,200원 |
| 예상 전환율 | 2~3% | 15~20% |
| 절대 전환 수 | 10~15명 | 12~16명 |

비용은 1/5로 줄고 효과는 유사하거나 더 좋다.

## 차단 고객 처리 플로우

```text
발송 시도
  -> 실패 (KKO_1021 / KKO_1025 / KKO_E18 차단 코드)
    -> DB에 차단 상태 기록
    -> 이후 세그먼트에서 자동 제외 (인원수에 반영)
    -> 30일 후 1회 재시도 -> 성공 시 복구
```

- 발송 실패 건은 과금되지 않음 (성공 건만 과금)
- 알림톡 차단 시 SMS 대체발송 가능 (광고성 메시지는 대체발송 없음)

## 대량 사용 매장 예외 처리

### 원칙

- 99%의 소규모 매장은 "무제한 무료"로 체감
- 극단적 대량 사용 매장은 **약관으로 방어**, 자동 차단 없음
- "잘 되다가 갑자기 안 됨" 상황 원천 차단

### 기준

| 지표 | 기준 |
|------|------|
| 월 알림톡 발송량 | **3,000건 이상** |
| 환산 예약 건수 | 약 1,000건/월 (일 33건 이상) |

### 처리 플로우

```text
월 2,500건 도달 (경고 단계)
  -> 사장님 대시보드 알림: "다음 달 상위 플랜 안내 예정입니다"

월 3,000건 초과 2개월 연속
  -> 자동 차단 없음
  -> 사장님에게 상담 안내
  -> 상위 플랜 전환 협의
```

### 이용약관 문구 (예시)

> "정상적인 예약 운영을 현저히 초과하는 알림톡 발송(월 3,000건 이상)이 지속될 경우, 회사는 상위 플랜 전환 또는 별도 협의를 제안할 수 있습니다."

### 근거

- 공비서도 "무제한 무료"를 마케팅하지만 6.9만 매장 규모에서 극단 케이스는 관리하고 있을 것으로 추정
- 자동 차단은 예약 알림 끊김 위험 → UX 치명적
- 약관 + 상담 기반 처리가 사장님 운영 안정성 보장
