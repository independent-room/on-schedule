# Customer UI Kit — 고객 모바일 예약 페이지

390px 모바일 너비, 사장님이 카카오 채널/인스타 프로필에 링크하는 가게별 예약 페이지.

## 컴포넌트
- `StoreHeader` — 가게 이름·주소·영업시간.
- `StepBar` — 3단계 프로그레스 (메뉴 → 시간 → 결제).
- `MenuItem` — 메뉴 카드 (이미지/이름/설명/가격, selected 보더 강조).
- `TimeSlot` — 30분 단위 시간 그리드. 불가/선택 상태.
- `Summary` — 크림색 배경 요약 패널.
- `FixedBottom` — 화면 하단 고정 CTA (sticky + blur).
- `SuccessScreen` — 예약 완료 화면.

## 데모 시나리오
1. 메뉴 선택 → 다음.
2. 픽업 시간 선택 → 다음.
3. 카카오페이/카드 선택 후 30% 선입금 → 예약 완료 화면 + 알림톡 발송 안내.
