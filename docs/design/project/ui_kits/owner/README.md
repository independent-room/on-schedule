# Owner UI Kit — 사장님 대시보드

웹 위주(데스크톱 우선) 사장님 대시보드. `index.html`이 클릭스루 데모.

## 컴포넌트
- `Sidebar` — 좌측 네비. 6개 섹션 (오늘 예약, 캘린더, 고객, 메뉴, 알림톡, 통계).
- `Topbar` — 페이지 타이틀 + 서브타이틀 + 우측 액션.
- `KpiRow` — 4-col KPI 카드 (오늘 예약, 매출, 노쇼율, 알림톡).
- `ReservationCard` — 예약 1건. 시간/날짜/고객명/메뉴/상태/액션.
- `TodayList` — 오늘 예약 리스트 + 필터 칩.
- `AlimtalkModal` — 알림톡 발송 미리보기 + 발송 모달.
- `Badge`, `Chip`, `btnPrimary`, `btnSecondary` — 유틸.

## 데모 시나리오
1. 진입 시 오늘 예약 5건 표시 (확정 2 + 대기 2 + 노쇼 1).
2. "확정" 버튼 클릭 → 대기 카드가 확정으로 바뀜.
3. "픽업 완료" 버튼 → 카드 사라짐.
4. 하단 "알림톡 보내기" → 카카오 알림톡 미리보기 모달.
