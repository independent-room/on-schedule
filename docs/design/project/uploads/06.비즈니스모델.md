# 비즈니스 모델

## 수익 모델 방향: 예약 규모 기반 월 구독

| 플랜 | 월 예약 | 구독료 | 마진 |
|---|---|---|---|
| 스타터 | ~100건 | 3만원 | ~80% |
| 그로우 | ~300건 | 5만원 | ~64% |
| 프로 | 500건+ | 8만원 | ~56% |

- 예약이 늘어날수록 자연스럽게 업그레이드 유도
- 대형 가게일수록 매출이 크므로 더 높은 구독료 납득 가능
- "네이버 예약 3.74% 수수료 대비 월 8만원 정액"은 압도적으로 저렴

> 미확정: 티어별 포함 메시지 건수 한도, 초과 시 처리 방식 (업그레이드 유도 vs 건당 추가 과금)

## 비용 구조

### 고정 비용

| 항목 | 월 비용 (예상) |
|---|---|
| 서버/인프라 | 5~10만원 |
| PG 가입비/관리비 | 약 2.7만원 (연 33만원 / 12) |
| 도메인/기타 | 1~2만원 |
| **합계** | **약 10~15만원** |

### 변동 비용

| 항목 | 단가 |
|---|---|
| 카카오 알림톡 | 건당 ~9원 |
| 브랜드메시지 (텍스트) | 건당 ~18원 |
| SMS 대체발송 | 건당 ~12원 |
| LMS 대체발송 | 건당 ~35원 |

### 가게 규모별 월 원가 시뮬레이션

| 구분 | 중소 (월 100건) | 대형 (월 500건) |
|---|---|---|
| 알림톡 (3건/예약) | 300건 x 9원 = 2,700원 | 1,500건 x 9원 = 13,500원 |
| 마케팅 (스마트 타겟팅) | 200건 x 18원 = 3,600원 | 400건 x 18원 = 7,200원 |
| **합계** | **~6,300원** | **~20,700원** |

## 손익 분기점

| 월 구독료 | 손익 분기 고객 수 |
|---|---|
| 3만원 | 4~5곳 |
| 5만원 | 2~3곳 |

## 지불 의향 가설 (미검증)

> 노쇼 관리 + 카카오 알림톡 + 낮은 결제 수수료가 포함된 예약 도구에 월 3~5만원을 지불할 의향이 있다.

**가격 맥락:**

| 비교 항목 | 네이버 예약 | 우리 서비스 |
|---|---|---|
| 기본 요금 | 무료 | 월 3~5만원 |
| 결제 수수료 | 3.74% | 미확정 (가상계좌 시 건당 400원 등) |
| 월 매출 500만원 기준 총 비용 | ~18.7만원 | 3~5만원 + a |

→ 검증 방법은 04.고객발견.md 3단계(랜딩페이지 테스트) 참조

## 1인 운영 가능성 가설 (미검증)

> AI 생산성을 활용해 1인으로 개발/운영하면 소수 유료 고객만으로도 수익성을 확보할 수 있다.

**성공 기준:**

- MVP를 2~3개월 내 출시 가능
- 출시 후 6개월 내 유료 고객 5곳 이상 확보
- 고객 지원이 주당 5시간 이내로 관리 가능
