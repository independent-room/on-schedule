# 유저 획득 전략

## GTM 단계 구분

- **1단계(현재 ~ PMF)**: 베이커리/디저트 사장님 집중 공략. 본 문서의 모든 채널/콘텐츠는 1단계 기준으로 작성됨.
- **2단계(PMF 후)**: 카페, 공방/원데이클래스, 꽃집 등 인접 예약형 업종으로 수평 확장. 업종별 뉴스레터/커뮤니티/랜딩 분기 운영.

## 핵심 채널: 뉴스레터 (GTM 1단계)

서비스 기능이 아닌 고객 획득 채널.
사장님들의 신뢰를 쌓고 유료 전환으로 연결하는 퍼널.

```text
뉴스레터 구독 (무료) -> 신뢰/커뮤니티 구축 -> 예약 SaaS 베타 초대 -> 유료 전환
```

### 콘텐츠 방향

- 전세계 베이커리 시장 소식 큐레이션 (트렌드, 원재료 시세, 성공/실패 사례)
- 사장님이 바로 써먹을 수 있는 인사이트 ("이번 주 일본에서 뜬 디저트" 등)
- 트렌드 레시피 가이드: "뜨는 이유 + 만드는 법" 세트로 제공

AI로 트렌드 감지 + 레시피 초안 생성 -> 검수 후 발송. 레시피 정확도가 신뢰에 직결되므로 AI 단독 발행 금지.

### 소싱 방법

| 소스 | 언어 | 내용 |
|---|---|---|
| Bake Magazine | 영어 | 글로벌 제빵 업계 뉴스 |
| Modern Baking | 영어 | 미국 베이커리 트렌드 |
| British Baker | 영어 | 유럽 베이커리 시장 |
| 일본 제과제빵 매체 | 일어 | 아시아 트렌드 |
| 국내 식품 뉴스 | 한국어 | 원재료, 규제, 업계 동향 |

### 수익화 경로

| 단계 | 활동 | 목표 |
|---|---|---|
| 1단계 | 뉴스레터 무료 발행 (주 1회) | 구독자 500명 |
| 2단계 | 커뮤니티 형성 (카톡 오픈채팅 등) | 사장님 네트워크 |
| 3단계 | 예약 SaaS 베타 초대 | 무료 사용자 확보 |
| 4단계 | 유료 전환 | 월 구독 3~5만원 |
