# 시장 규모 추정

> 이 문서는 아이디에이션 대상입니다. brainstorming 스킬로 구체화 필요.

## 현재 수준

TAM/SAM/SOM 추정이 전혀 없다. "이게 사업이 되는 규모인가"를 판단할 수 없는 상태.

## 추정 필요 항목

> 제품은 업종 비종속이므로 시장은 2단으로 추정한다.
> **(A) 초기 GTM 시장(베이커리/디저트)** — 비치헤드 검증용 / **(B) 확장 시장(예약형 소상공인 전체)** — 장기 천장 추정용.

### TAM (전체 시장)

- [ ] 한국 예약형 소상공인 사업체 수 전체 (베이커리, 카페, 공방, 꽃집, 반찬, 스튜디오 등)
- [ ] 예약제를 운영하는 비율
- [ ] 관련 예약/CRM SaaS 시장 규모

### SAM-A (1차 GTM 유효 시장 - 베이커리/디저트)

- [ ] 한국 베이커리/디저트 사업체 수
- [ ] DM/카톡으로 예약을 받는 비율
- [ ] 월 3~5만원 구독료를 지불할 수 있는 매출 규모의 가게 수

### SAM-B (확장 후 유효 시장)

- [ ] 인접 업종(카페·공방·꽃집 등)에서 DM/카톡 예약 비율
- [ ] 동일 가격대 지불 의향 추정

### SOM (점유 가능 시장)

- [ ] 초기 1년 내 현실적으로 확보 가능한 베이커리/디저트 고객 수
- [ ] 2~3년차 인접 업종 확장 시 추가 확보 가능 수
- [ ] 지역/채널별 접근 가능 범위

## 참고할 수 있는 데이터 소스

- 통계청 사업체 조사 (제과점업 + 인접 예약형 업종)
- 소상공인시장진흥공단 데이터
- 네이버 지도 카테고리별 등록 업체 수 (베이커리·디저트·카페·공방 등)
- 배달의민족/카카오맵 카테고리별 업체 수
