# 문제 정의

## 누가 어떤 불편을 겪는가

소규모 사장님들이 카톡 DM/인스타 DM으로 예약을 관리하면서 다음 문제를 겪고 있다. 본 서비스는 업종 비종속적 코어를 지향하되, **초기 GTM 타겟은 베이커리/디저트**로 잡는다(이유는 01.서비스개요.md 참조).

- 주문 누락
- 노쇼 (예약 부도)
- 수동 알림 (확정/리마인드를 일일이 보내야 함)
- 중복 예약 (일일 생산량 초과)

## 노쇼 현황 데이터 (2025~2026)

| 지표 | 수치 | 출처 |
|---|---|---|
| 외식업 노쇼 피해 경험률 | 65% (최근 3년) | 한국경제 2026.01 |
| 피해 점포당 평균 횟수 | 3년간 8.6회 | 한국경제 2026.01 |
| 1회당 평균 손실액 | 44.3만원 | 한국경제 2026.01 |
| 예약보증금 설정 비율 | 14%에 불과 | 한국경제 2026.01 |
| 커피전문점 노쇼 횟수 | 13.5회 (업종 2위) | 서울경제 |

**핵심 시사점**: 노쇼는 여전히 심각하고, 예약보증금을 설정한 곳이 14%밖에 안 됨 = **도구가 없어서 못하고 있다는 신호.**

## 기존 대안이 불충분한 이유

### 네이버 예약의 한계

| 한계점 | 영향 |
|---|---|
| 결제 수수료 3.74% | 월 매출 500만원 기준 약 18.7만원 부담 |
| 자동 확정 (거절 불가) | 수용 불가한 주문도 자동 수락됨 |
| 시간 설정 제한 (30분/1시간) | 픽업/예약 시간 유연성 부족 (베이커리·공방·반찬가게 등) |
| 중복 예약 발생 | 일일 생산량 초과 주문 가능 |
| CRM 없음 | 단골 관리, 노쇼 이력 추적 불가 |

### 한국 경쟁 서비스 현황

범용 예약 SaaS는 캐치테이블(레스토랑), 콜라보살롱(뷰티) 등이 자기 업종에 깊게 특화돼 있어 베이커리/디저트·공방 등 비주류 업종은 사실상 미충족 상태. 특히 베이커리/디저트 특화 SaaS는 한국에 부재 — 초기 진입 공백이 명확.

## Vitamin vs Painkiller vs Antibiotic

**Painkiller**에 해당한다.

- 노쇼 1건당 평균 44.3만원 손실은 실질적 금전 피해
- DM 기반 수동 관리는 매일 반복되는 운영 부담
- "있으면 좋은" 수준이 아니라 "없으면 돈을 잃는" 수준

## 가설 vs 검증 상태

| 가설 | 검증 상태 | 근거 |
|---|---|---|
| DM 기반 예약을 받는 소규모 사장님(특히 베이커리/디저트)이 예약/노쇼 문제를 겪고 있다 | 부분 검증 | 지금예약 경험 + 노쇼 통계 |
| 네이버 예약이 니즈를 충분히 해결하지 못한다 | 부분 검증 | 알려진 한계점 (직접 인터뷰 미실시) |
| 월 3~5만원 지불 의향이 있다 | 부분 검증 | 지금예약에서 유료 사용자 존재 |
| 1인 운영이 가능하다 | 미검증 | 개발 과정에서 검증 필요 |
