# 서비스 개요

## 한 줄 정의

소규모 사장님을 위한 **확장 가능한 예약·주문 관리 B2B SaaS**. 카톡 DM/인스타 DM으로 예약을 받던 흐름을 대체하고, 노쇼 관리와 카카오 알림톡을 핵심으로 제공한다.

## 포지셔닝 원칙

- **제품**: 업종 비종속적인 범용 예약/주문 관리 코어 (예약 폼, 노쇼 관리, 알림톡, 결제). 업종별 디테일은 설정/확장 모듈로 처리.
- **초기 GTM 타겟**: 베이커리/디저트. 이유는 (1) 지금예약 경험상 유료 전환율 가장 높았고, (2) 한국에 베이커리 특화 예약 SaaS가 부재한 니치 공백이 열려 있기 때문.
- **확장 경로**: 베이커리/디저트에서 PMF 확보 → 인접 픽업/예약형 업종(카페, 공방/원데이클래스, 꽃집, 정육/반찬, 소규모 스튜디오 등)으로 수평 확장.

## 레퍼런스

**지금예약 ((주)루머) — 창업자 실무 경험**

- 예약 관리 SaaS (베이커리, 타투, 반영구 등 복수 업종)
- 유료 전환 사용자 존재 확인
- 실패 원인 분석 완료 → 이번 서비스에 반영

## 서비스 목적

지금예약에서 배운 실패 원인을 보완한 새로운 접근.

| 지금예약 실패 원인 | 이번에 다르게 할 것 |
|---|---|
| 7명 인건비 감당 불가 | 1인 운영 + AI 생산성 |
| 기능 중구난방 (부가 유틸 위주) | 예약 효율 핵심 기능에만 집중 |
| 타겟 분산 (베이커리, 타투, 반영구 등을 동시에) | 범용 코어로 만들되 **GTM은 베이커리/디저트 한 곳에 집중** → PMF 후 확장 |
| MVP 품질 저하 | 높은 초기 품질 (기술력 성장 + AI) |
| SNS 광고 1000만원 효과 미미 | 커뮤니티 기반 + 랜딩페이지 검증 |

## 이미 확인된 신호 (지금예약 경험)

- 베이커리/디저트 업종이 유료 전환 비율 가장 높았음
- 유료 전환 핵심 이유: **노쇼 관리 + 카카오 알림톡**
- 유료 사용자는 존재했음 (= 시장 자체는 있음)

## 핵심 가치 제안 (초안)

1. 노쇼 걱정 없는 예약 관리 (선결제/보증금 + 노쇼 이력)
2. 카카오 알림톡 자동 발송 (예약 확정, 리마인드, 픽업 완료)
3. 네이버 예약 대비 압도적으로 낮은 수수료
