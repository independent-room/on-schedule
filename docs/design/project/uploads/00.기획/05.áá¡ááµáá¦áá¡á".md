## 현재 수준

네이버 예약 대비 비교표는 존재하지만, "왜 이 서비스를 써야 하는가"가 한 문장으로 정리되지 않았다.

## 기존 대안 대비 차별점 (초안)

| 비교 항목 | 네이버 예약 | 우리 서비스 |
|---|---|---|
| 기본 요금 | 무료 | 월 3~5만원 |
| 결제 수수료 | 3.74% | 영세 가맹점 0.4% (PG 직접) |
| 예약 확정 방식 | 자동 확정 (거절 불가) | 사장님 직접 확정/거절 |
| 픽업 시간 | 30분/1시간 고정 | 자유 설정 |
| 중복 예약 | 발생 가능 | 일일 최대 수량 설정 |
| 노쇼 관리 | 없음 | 선결제/보증금 + 이력 관리 |
| CRM | 없음 | 자동 고객 프로필 + 세그먼트 |
| 알림톡 | 없음 | 자동 발송 (확정/리마인드/완료) |
